# Aura3D Showcase - Data Galaxy Explorer

Standalone showcase app for a dense AI/data visualization route. The route is
built with public `@aura3d/engine` APIs and stages CLI-resolved typed assets
around the data field.

## Remediation Status

- Classification: internal-diagnostic; compiler-selected diagnostic anchor applied.
- Route health: `apps/showcase-data-galaxy/route-health.json`.
- Asset status: `assets.showcaseParticleCore` is the compiler-selected typed
  diagnostic anchor, not proof of a real data product.
- Rejected asset: `assets.showcaseDataStation` was removed from the live primary
  path after retained route-primary evidence marked it unreadable.
- Primitive status: the data field, attractors, KPI markers, arcs, and streams
  are heavy abstract procedural set dressing.
- Claim status: bounded to an abstract Aura3D data visualization prototype. It
  must not claim native GPU-compute particles or meaningful real-data
  exploration until the data model and pixel evidence are rebuilt.

## Source Anchors

- `sceneKits.dataViz(...)` for the chart base, axes, labels, hover target, and camera-ready data matrix.
- `model(assets.showcaseParticleCore)` for the typed data-reactor hero and diagnostic anchor resolved through the Aura3D CLI.
- `charts.visualQA(...)` for structural chart evidence.
- `effects.particles(...)` and `particles.diagnostics(...)` for dense procedural particle systems and budget reporting.
- `primitives.*`, `labels.*`, `lights.*`, `interactions.*`, `camera.*`, and `timeline.*` for semantic axes, KPI markers, segment clusters, attractors, streams, arcs, labels, controls, and camera modes.

## Controls

- Formation: Galaxy, Sphere, Vortex, Network, Wave.
- Camera: Overview, Focus, Orbital, Flythrough.
- Particles: adjusts the requested particle effect budget.
- Flow Speed: updates route timing, particle emission, and runtime animation.
- Performance: Balanced, Dense, Cinematic.
- Connection Arcs: toggles attractor connection geometry.

## Evidence

The route publishes `window.__AURA3D_SHOWCASE_DATA_GALAXY__` with:

- `status`
- `appId`
- `frameCount`
- `interactionState`
- `controls`
- `systems`
- `claimBoundary`
- `diagnostics`

Claim boundary: this is an Aura3D internal diagnostic route using a CLI-resolved
typed data-reactor anchor, scene kits, particles, labels, interactions, camera
presets, and runtime node evidence. It does not claim native GPU-compute
particle simulation or public release readiness.

The chart field, attractors, orbit rings, labels, lights, effects, and
interaction controls are authored with Aura3D public APIs.

CSS is limited to the topbar, panels, controls, and responsive layout. The data
field, particles, axes, labels, segment clusters, typed station, and runtime KPI
marker are Aura3D scene content.
