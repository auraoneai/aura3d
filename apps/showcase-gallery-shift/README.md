# Gallery Shift

Gallery Shift is a root-safe Aura3D stealth prototype. The route uses `createGameApp` and public Rapier-backed raycasts/sensors, while patrol movement, hearing radii, collision pushout, and two-floor waypoint navigation are deterministic route-local authored logic. It does not claim a reusable stealth, AI, navigation, or animation-event kit.

## Mission

Lift two exhibits on Marble Hall, enter Skyline Wing, lift the third exhibit, and return to the service exit during the controlled alarm. Detection is determined by published range/angle parameters and public-physics line-of-sight queries against the same walls, display cases, and pedestals visible in the route. Walking emits a 3 m authored noise event, sprinting 6 m, and sneaking 0 m; the third lift activates faster patrols and a two-second escape grace so the alarm does not catch the player inside the lift animation.

Keyboard controls are WASD/arrows to move, Shift to toggle sneak, X to sprint, E to hold/lift, P/Escape to pause, and R to restart the current floor (or the full mission after a win). Named touch buttons provide move, sneak, lift, pause, and reset parity.

The thief and humanoid sentry use embedded animation clips from typed assets. The
second patrol is an already-registered industrial security rover whose motion is
the same deterministic authored transform (the rover has no embedded humanoid
clips). Footsteps are driven by a distance-based authored gait because the
selected humanoid clips contain no clip-local footstep metadata; perception
truth never depends on guessed animation frames. Two-floor navigation is
authored waypoint movement, not Recast/navmesh.

`?debug=1` enables deterministic browser-test controls without rendering overlays. `?debug=visual` additionally renders optional perception diagnostics; exact release-review artifacts never use that mode.

## Evidence boundary

Machine evidence is generated by the focused unit/browser suites and the route scripts in `scripts/`. `route-health.json`, `deploy-report.json`, `performance-report.json`, screenshots, and receipts are generated artifacts. Machine completion does not approve public promotion: independent review of the exact hash-bound artifact family remains mandatory and must not be self-attested.

Run focused checks from the repository root:

```bash
pnpm --dir apps/showcase-gallery-shift typecheck
pnpm --dir apps/showcase-gallery-shift build
pnpm exec vitest run tests/unit/apps/gallery-shift-vision.test.ts tests/unit/apps/gallery-shift-patrols.test.ts
pnpm exec playwright test tests/browser/gallery-shift-playable.spec.ts tests/browser/gallery-shift-scene.spec.ts
pnpm --dir apps/showcase-gallery-shift write:deploy
pnpm --dir apps/showcase-gallery-shift write:performance
pnpm --dir apps/showcase-gallery-shift write:route-health
```
