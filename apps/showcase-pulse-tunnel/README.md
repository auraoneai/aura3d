# Pulse Tunnel

Single-path rhythm runner built on `createGame` and the salvaged Pulse Tunnel gameplay core (`src/gameplay/{beat-clock,gates,patterns,player,style,conveyor}.ts`). Gates and walls stream on a 120 BPM authored chart across four sections (`intro` -> `build` -> `drop` -> `finale`); you switch lanes, jump low gates, slide under high gates, and graze near-misses for style multipliers.

## Architecture

- **Single-path entry (`src/main.ts`)**: Every URL boots `createGame` (`id: "showcase-pulse-tunnel"`, `qualityRebuild: { flags: ["game"] }`). The legacy/v2 dual-path dispatcher has been retired.
- **Salvaged gameplay core**:
  - `src/gameplay/beat-clock.ts` — 120 BPM beat clock with ±80 ms drift tolerance over 3 consecutive checks and deterministic pattern-mode fallback when headless or when drift exceeds tolerance.
  - `src/gameplay/gates.ts` — Gate scheduling, pass/graze/collision classification, and seek respacing.
  - `src/gameplay/patterns.ts` — Authored 90-second chart across `intro`, `build`, `drop`, and `finale`.
  - `src/gameplay/player.ts` — Three-lane switching, jump/slide kinematics, and shield invulnerability windows.
  - `src/gameplay/style.ts` — Distance/graze heat, multiplier, and score accumulation.
  - `src/gameplay/conveyor.ts` — Instanced tunnel hoop segment pool recycling.
- **App-local typed assets (`aura.assets.json`, `src/aura-assets.ts`)**:
  - Models: `pulseRunnerCraft`, `pulseReactorEncounterWorld`, `pulseTerminalSentry` (staged in `public/aura-assets/`).
  - Audio: 4 music stems (`pulseDrumsStem`, `pulseBassStem`, `pulseLeadStem`, `pulseAirStem` generated by `scripts/build-music.mjs`) and 9 SFX cues (`pulseLaneSwitchSfx`, `pulseJumpSfx`, `pulseSlideSfx`, `pulseGrazeSfx`, `pulseShieldHitSfx`, `pulseShieldBreakSfx`, `pulseSectionRiseSfx`, `pulseRunOverSfx`, `pulseUiConfirmSfx`).
  - Environment: `synthwaveDomeHdr` (`assets/env/data_galaxy_deep_space_1k.hdr`).

## Controls

| Input | Action |
| --- | --- |
| `A` / `D` or `Left` / `Right` | Switch lane (buffered 90 ms) |
| `W` / `Up` / `Space` | Jump over low gates |
| `S` / `Down` | Slide under high gates |
| `Enter` / `J` | Start / confirm |
| `P` / `Escape` | Pause / resume |
| `R` | Reset to ready state |

Touch (`lane-swipe` preset): horizontal swipe switches lanes, swipe up jumps, swipe down slides, tap starts/confirms.
