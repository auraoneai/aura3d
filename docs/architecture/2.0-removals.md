# Aura3D 2.0 removals and retrieval

Status: current migration record for Aura3D 2.0.0

Git history is the archive. Superseded prompts, PRDs, handoffs, duplicate
documentation, private workspaces, fabricated capability facades, and displaced
commodity implementations are not retained in the current documentation tree.

To inspect a removed path without changing the worktree:

```bash
git show <commit>^:<path>
```

To restore a path deliberately:

```bash
git checkout <commit>^ -- <path>
```

## Product and package removals

- `packages/test-utils` was private, unexported, and had no current product
  consumer.
- Fabricated rendering-compatibility bookkeeping that returned hard-coded
  success without a device, context, draw call, or image was removed. The real
  `@aura3d/three-compat` migration package and real animation compatibility
  helpers remain.
- Hand-written physical solver ownership, character/navigation/crowd solver
  implementations, and cloth/soft-body/fracture/fluid/fire fixture APIs were
  removed from the 2.0 public contract. Rapier and Recast/Detour are the selected
  optional owners. Exact symbol replacements are documented in
  [`MIGRATION-2.0.md`](../../MIGRATION-2.0.md).
- Browser capture and Node encoding/publishing were separated. Node utilities
  are reachable only through `@aura3d/engine/media-node`.

## Documentation consolidation

The 2.0 documentation pass removes obsolete archive Markdown and folds useful
decisions from the 1.x PRDs, game-engine PRD, execution plans, audits, release
handoffs, and per-version release-note drafts into the current architecture,
migration, status, examples, comparison, and release documents. The current
source of truth is the documentation index, not a historical planning file.

## Decisions retained after attempted removal

- ECS and scripting remain compatibility-only because their exported contracts
  and consumers require a major-version migration path.
- Typed assets, renderer internals, application workflows, and public scaffolds
  remain because they are part of Aura3D's owned core or platform moat.
- Historical benchmark results required to reproduce a current comparison may
  remain as frozen data, but they cannot establish a current public claim.

The executable package/symbol comparison against `v1.5.2` is
`pnpm check:public-surface-diff`; subsystem ownership is verified by
`pnpm check:final-subsystem-ownership`.
