  lane on, `"auto"` lets phones follow the device. That is the wanted behaviour now that the game has touch controls.
- So production pixels, pixel-ratio cap and gameplay are unchanged, and no remote capture was taken for this change. The
  only visible effect is that E1's `RENDERER_QUALITY_STRING` diagnostic no longer fires for this game.
