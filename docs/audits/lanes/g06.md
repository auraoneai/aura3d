# Lane G06: Pip's Big Leap (`pips-big-leap`)

Branch `audit-fix/g06`, cut from `audit-fix/integration` (b2dba3713). App `apps/showcase-pips-big-leap`. The app mounts no `examples/<dir>`: every source file is under the app folder (`rg -n "examples/" apps/showcase-pips-big-leap/src` finds nothing), so the lane owns the app folder, `tests/unit/pips-big-leap/`, `tests/browser/audit-fix/pips-big-leap.spec.ts`, `evidence/pips-big-leap/` and `docs/upgrade-4.5.0/pips-big-leap.md`.

All browser numbers come from the remote ACR runner (software WebGL2, SwiftShader, about one presented frame every several seconds). They show layout, content, luma and engine counters; they are not real-GPU frame times. Steady-state values are the later shot of each pair (35 s), not the first frame. Evidence: `evidence/pips-big-leap/audit-2026-10-29/<run>/` (decoded JPEGs plus `meta.jsonl`, decoder `decode.mjs`).

Meshy spend: 0 credits (no new or replaced models; the six bespoke GLBs were optimized with `aura3d assets optimize`).

## Other changes found while verifying

- The Atlas and Studio card fonts had no fallback (`font: 500 20px/1 Graphik`), so they rendered in a serif face wherever Graphik is missing (seen on the runner). Fixed in 25946b56b.
- Four of the six bespoke GLBs no longer matched their manifest hash and size (bytes had been replaced without re-admission). The re-admission in e722353b6 makes the manifest match the files.
- `world.ts` comment "legacy-post safe" on contact shadows corrected (d1f38ec28).
- Holding D on the start platform now really strafes, so a long hold runs Pip off the 9 m start platform (the after runs show two fall respawns). That is the expected result of C2, not a defect.
