The rig comment and `PORTING-NOTES.md:39` say the original chapter-0 rig is "key 2.2, sky/ground 1.05". The code had 1.45 for day chapters (from `a958dcbca`, 4.0.8). That number was tuned while the engine dropped the hemisphere next to an environment (LIGHT-05), so 1.45 never reached a pixel. The retune moves the steady-state mean by -0.4% (120.78 to 120.31), and most of that is in the middle band (-1.1%), where the terrain and walls are. The shot times differ: the 75 s shot landed 359 s after ready in the control run and 289 s in the new run, because software GL presents slowly, and the title camera orbits during that time. So the difference sits near the noise between runs. The scene is still +3.4% over E2's no-hemisphere base. The cel pass (`custom:prd03.custom.silt-cel`, tone mapping `none`) bands luma, which flattens small lighting changes. Both runs report `renderPath hdr-msaa`, `dropped []`, `missing []`, and no warnings.

The retune is kept because it restores the documented original rig. It is not kept for a luma target: the brightening E2 measured is mostly not undone by it and a 3.4% lift on a cel-banded daytime frame with 0% black and p95 207 is not a defect.
