# Lane G01: Aura Slam 3D (`top-tennis`)

Branch `audit-fix/g01`, cut from `audit-fix/integration`. App `apps/showcase-top-tennis` is a wrapper that imports `examples/aura-slam/main`; no other live game imports `examples/aura-slam` (`rg -l examples/aura-slam apps examples packages` finds only this app and two skill reference docs), so this lane owns it.

Checks on the final commit:

- `node tools/game-checks/run.mjs top-tennis`: 0 errors, 0 warnings.
- `pnpm exec vitest run tests/unit/aura-slam`: 27 files, 319 passed, 1 skipped, 1 todo. New file `tests/unit/aura-slam/audit-fixes.test.ts` (32 tests, one block per row). `tests/unit/game-kits/racket-scoring.test.ts` and `tests/unit/game/binding-store.test.ts` (the other importers) pass.

- The replay gate (`tests/unit/aura-slam/replay.test.ts` against `evidence/aura-slam/reference.json`) still passes after C4, because the replay harness already ran the adapter controller once per sim step. `reference.json` was not re-recorded.
