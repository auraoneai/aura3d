# Lane G20: Shadowstep Gauntlet (`ninja-runner-port`)

Branch `audit-fix/g20`, cut from `audit-fix/integration` (b2dba3713). Source: `apps/showcase-ninja-runner-port` mounts `examples/ninja-runner-port/main.ts` (plus `apps/showcase-port-shared/diag.ts`, which other ports share and this lane did not edit). No other live game imports `examples/ninja-runner-port` (`rg ninja-runner-port apps --glob '*.ts'` finds only this app), so this lane owns it.

All browser numbers are remote SwiftShader (software WebGL2) runs of `tests/browser/audit-fix/ninja-runner-port.spec.ts` on the example page (same module and body as the app page; the app page cannot run under the example dev server because bundling `apps/*/src/main.ts` moves `import.meta.url` and the GLB URLs 404). States are driven through the QA hooks with the game's frame loop stopped, so a shot is the same frame on every build (the `-b` repeat shots match to 0.01). Mean is canvas-only luma, 0-255. "Before" is the unmodified base in a temporary detached worktree; "v4.3.7" is the `v4.3.7` tag. Evidence: `evidence/ninja-runner-port/audit-2026-10-29/` (README there has the tables). Nothing here is real-GPU evidence.
