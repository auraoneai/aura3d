## Handoffs

- **E5**, `tests/browser/example-dev-server.ts`, `resolveRequest`: in the `aura-assets/` branch, also try `join(appPublic, normalizedPath)` for each `appPublicDirs(root)`, as the default branch does. - **E5**, `docs/agents/lessons-learned.md`: add "`primitives.box({ material, instanceColors })` multiplies the material colour by each instance colour. Set the palette in one of them, not both, or dark palettes go black (Bunker Zero floors 2-6, fixed in 949fe2259)."
