### LIGHT-01 calibration

Verified first: `world.ts` authored only `lights.hemisphere` and `lights.directional`, no `environments.*` node, so 4.5.0 gave the lit Meshy models no IBL. Fix: `b.add(environments.neutral({ name: "model-fill", intensity: NEUTRAL_FILL }))`, `NEUTRAL_FILL = 1.0`, background off (the authored sky and unlit custom shaders are unchanged). Unit test: `tests/unit/heatsink-port/environment.test.ts` (one neutral environment with the calibrated intensity and no background; hemisphere and key lights kept).

Method: spec `tests/browser/audit-fix/heatsink-port.spec.ts`, `?manual=1`, replays the recorded reference script to steps 450, 1200 and 2250, renders the last 8 steps and reads the canvas in the same task, so all builds render identical game state. The lit-model mask is every 4x4 block whose luma differs by more than 3 between 4.3.7 and the 4.5.0 base (only the PBR models change there). The calibration arms ran on a throwaway worktree of this branch with `audit-fix/e2` merged (directional hemisphere next to the environment, LIGHT-05/08) and a temporary `?hpIbl=` URL override; the override is not on the branch.
