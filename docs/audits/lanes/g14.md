# Lane G14: Cross Hop (`apps/showcase-cross-hop`)

Branch `audit-fix/g14`, cut from `audit-fix/integration` (b2dba3713). Wave 1 left no commits on this branch; wave 2 added only the report commit a4bcbab59. Everything below was done in this pass.

The app mounts only its own code (`apps/showcase-cross-hop/src`, no `examples/` directory) plus `apps/showcase-port-shared/quickbar.css`, which other games also import and which I did not touch. The game loads its own asset manifest (`src/aura-assets.ts`), not the shared catalog.

Remote runs are SwiftShader (software WebGL2) on the ACR runner. They show layout, content and luma, not GPU look or frame rate. Luma is the mean of the canvas-only frame at the later shot (75 s or 90 s after ready).

### 4.3.7 baseline

| Build | Run | Emberline (theme 3) | Neon District (theme 4) |
|---|---|---|---|
| v4.3.7 | g14v437-themes | 61.19; 15; 2.1% | 64.20; 26; 0.9% |
| 4.5.0 base (`audit-fix/integration`) | g14before-themes-r | 67.41 (+10.2%); 17; 1.2% | 70.70 (+10.1%); 30; 0.3% |
| lane `audit-fix/g14` | g14after-themes | 67.90 (+11.0%); 19; 0.9% | 70.88 (+10.4%); 30; 0.3% |
| lane + E1 + E2 | g14combo-themes2 | 57.27 (-6.4%); 14; 1.9% | 59.65 (-7.1%); 22; 2.1% |

4.5.0 made both night themes about 10% brighter than 4.3.7 (the look fill stacking on the ambient light). With the E1 and E2 fixes they end about 7% darker than 4.3.7, with a dark-pixel share close to 4.3.7's. I did not retune the game's lights: the retune would have to be made against the merged engine, the frames stay readable, and night themes slightly darker than before are within the look these themes aim for. If the integration gate wants 4.3.7 parity, raising the ambient for themes 3 and 4 only is the game-side knob.
