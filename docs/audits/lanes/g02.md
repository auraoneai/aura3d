Branch `audit-fix/g02`, cut from `audit-fix/integration` (b2dba3713). Source: `apps/showcase-roadster-rush` only (it mounts no `examples/` directory). "Before" is the 4.5.0 game source (b2dba3713, runs `g02b-20261029T131209Z-*`); "after" is this branch (runs `g02c-20261029T140227Z-*`, built at 5c4087761). `sim` and `drawn` below count what the simulation holds and what the renderer draws within 120 m ahead of the player, read in the page.
