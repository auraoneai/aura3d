# Lane G23: The Bellkeeper's Walk (`where-the-wind-wanders-port`)

Branch `audit-fix/g23`, cut from `audit-fix/integration` (b2dba3713). The app `apps/showcase-where-the-wind-wanders-port` is a 3-line wrapper that mounts `examples/where-the-wind-wanders-port/main.ts` (plus `apps/showcase-port-shared/diag.ts`). `rg` finds no other live game that imports `examples/where-the-wind-wanders-port`, so this lane owns it. The game does not import the shared root asset catalog (`src/aura-assets`): it loads its own `MODEL_ASSETS` table.

All browser numbers come from the remote runner (`tools/remote-acr/run.sh`, ACR, SwiftShader software WebGL2), not from a GPU. The spec is `tests/browser/audit-fix/where-the-wind-wanders-port.spec.ts`. BEFORE is `audit-fix/integration` b2dba3713 in a temporary detached worktree (`/tmp/before-g23`, with this spec copied in). AFTER is this branch. Frames and numbers are in `evidence/where-the-wind-wanders-port/audit-fix/` (see its README).

## Handoffs

- **E2** (post / bloom): `packages/engine/src/agent-api/nodes/types.ts` (the `AuraEffectNode` options used by `effects.bloom`) and `packages/engine/src/agent-api/nodes/effects.post.ts`: add `scatter?: number` to the public bloom options and pass it through the factory (it is already in `POST_EFFECT_FIELDS.bloom` and read by `mapBloomOptionsV2`). Why: WW-16; the v2 chain reports `post-field-deprecated:bloom.radius`, but games cannot author the replacement field. After that lands, the game changes `world.ts` `radius: 0.55` to `scatter: 0.55` (G23, one line).
