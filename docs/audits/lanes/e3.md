## Why SI-1 changes no pixels on the live games measured

Every live game except Shadowstep Gauntlet uses the default (4.2.0, "legacy") sun fit. In that fit `fitDirectionalCascades` adds every caster's bounds to every cascade's light box, so cascade 0 already contains the spread instances and the shader samples them (at coarse texels). The new pick then sees the same instance coverage in each cascade and keeps cascade 0 by the tie rule. The unit test "legacy (default) fit: ... the pick is unchanged" pins this. The audit's "no sun shadow" outcome needs a fit where cascades hug the frustum slice: the 4.3.0 fit (`__A3D_SHADOW_FIT__ = "current"`, Shadowstep Gauntlet), where the mock-Renderer test shows the change. Shadowstep Gauntlet's measured views have no spread instanced pool crossing a cascade split, so its frames match too. The fix therefore removes a latent defect and is pixel-neutral on what was measured; a game on the 4.3.0 fit with a pool that spans splits will gain shadows.
