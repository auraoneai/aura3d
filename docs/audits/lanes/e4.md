# Lane E4: animation, physics and API

Branch `audit-fix/e4`, cut from `audit-fix/integration` (b2dba3713). Rows: anim-phys-01..10 and SI-7 (anim-phys-11 is Iron Crown's, lane G05).

No live game uses `playLayer`, masks, `addClipsFrom`, `bindNodes`, scene physics, `Clock`, `AuraCanvas` or a 1,024-instance shadow-casting pool (audit "Animation, physics and API" and "Shadows and instancing"; rechecked below). The only change that reaches a live game is the new OPTION_IGNORED note on `model()` (anim-phys-06): Aura FC 3D and Aura Links 3D pass an `animation` key that `model()` never read. It adds a diagnostic and changes no pixels. The remote before/after run on Aura FC 3D is recorded under "Remote runs".

Each fix has a unit test that fails on the base sources and passes on the branch (checked by restoring the base file and rerunning the new test).
