## 19. Ion Circuit (`heatsink-port`)

**Live:** https://aura3d.auraone.ai/apps/ion-circuit/ · **Source:** `apps/showcase-heatsink-port` (mounts `examples/heatsink-port`) · **Genre:** racing

**State:** The live route loads cleanly. The page makes 44 requests with none failing, and all 9 Meshy GLBs return 200 at 0.95 to 1.93 MB each. Diagnostics report backend webgl2 on the hdr-msaa path with 68 to 90 draw calls and errors `[]`. In a Prism cloud browser (SwiftShader software GL, 0.27 fps at 1440x900), Start ran the 3-2-1 countdown, and holding W reached 117 km/h with dist going from -25 to 85 m and 0 crashes. Steady-state luma was 48.4 to 54.0 mean, with a 63 to 66 centre, 9 to 11% of pixels below 12 and 0% clipped. That is the darkest of the probed games and has the lowest colour variety (36 to 45 coarse colours). The game plays, but three defects reach every player: the "GO" banner never clears, barrels are mostly unhittable, and there are no touch controls.

**4.5.0 impact:** The app folder only got a version bump, and the game code in `examples/heatsink-port` did not change. Two engine changes do apply to it. (1) The scene authors only `lights.hemisphere` and `lights.directional` (world.ts:101-102), with no `environments.*` or `looks.*`. Under 4.5.0 the lit Meshy models (drone, barrels, pickups, pylons, scenery) therefore lose the implicit neutral-room IBL and get only a flat hemisphere mean, about 0.207 linear. Nobody has measured this, and the exposure-parity README states the opposite. (2) Fused bloom (`bloomFusion: 'separable'` on quality auto) replaces the 4.3.7 production bloom chain, and no per-game comparison was made. Both changes need a before-and-after capture before 4.5.0 can be called fine for this game.

**Tests and evidence gaps**

- `tests/browser/shotsb-circuit.spec.ts:21-24` force-hides `#count` before every frame, which masked HP-01. `heatsink-strike.spec.ts` checks only `textContent`.
- `evidence/heatsink-port/screens/final` (9e89ef082, 2026-10-25) predates the countdown CSS fix and 4.5.0. Its "results" frames show a race in progress, and no finished or DNF card has ever been captured. Draw calls were not recorded.
- There is no 4.3.7-vs-4.5.0 luma capture of the app route (LIGHT-01/02, RH-04). The upgrade guide `docs/upgrade-4.5.0/heatsink-port.md:51` says "I did not measure" the bloom change (RP-05). `game-render-path-parity.spec.ts` defaults to Thermal Drift, not this game.
- No unit test fires at real hover height (HP-02), and there is no browser test for touch or pause.
- No real-GPU run exists. All live numbers come from software GL at 0.27 fps.

**Dropped on verification**

- RP-04 (a typo in a debug URL switch blocks the mount) is engine-wide, not specific to this game, and is covered in the release section.
- LIGHT-08 (hemisphere applied as a flat mean) is an engine enhancement and is covered in the release section. Its effect here is folded into HP-04.
