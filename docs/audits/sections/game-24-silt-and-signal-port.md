## 24. Duneglide (`silt-and-signal-port`)

**Live:** https://aura3d.auraone.ai/apps/duneglide/ · **Source:** `apps/showcase-silt-and-signal-port` · **Genre:** arcade

**State:** The game loads and plays on production. The probe ran in Prism on SwiftShader software GL and saw 0 console errors and 0 failed requests, with renderPath `hdr-msaa`, 118 draw calls and 15 programs (3,392 ms compile). The title frame dropped from mean luma 173.5 at 3 s to 101.2 at 12 s. In play after 380 m of flight it read mean luma 114.4 with 0% black, and Begin, W-throttle, ring progress (1/8 to 4/8) and Esc pause all worked. Desktop chapter 0 works. Progression has hard faults: touch players cannot finish objective 2, and every later chapter reloads into QA mode. Chapters 1-6 also let the rider fly through hills. Health: degraded.

**4.5.0 impact:** The code needs no changes for the render-path updates, but the result is unmeasured. The scene authors `environments.neutral` (world.ts:177), `output`, bloom, colour grade, toon and custom shaders, so it stays on `hdr-msaa`. The implicit-environment and no-HDRI look changes do not apply. `main.ts:396` sets only the deprecated `qualityProfile`, so quality resolves to `auto`. That means separable bloom fusion and the cascade skip apply to its 3-cascade 4096 sun (world.ts:184). No 4.5.0 frames exist: the final screens were built at `0d965903c` on 2026-10-25. The `lights.hemisphere` at world.ts:178 is still dropped because an environment node is present (LIGHT-05). This matches 4.3.7, so it is not a regression.

**Tests and evidence gaps**

- No Duneglide frames exist from 4.5.0. Recapture title, mid-fly and results at 1280x720 and 390x844 on `/apps/duneglide/`, and record `diagnostics().renderPath` (quality `auto`, bloomFusion) (RH-05, LIGHT-02).
- Separable bloom fusion was never compared with `?aura3d-render=production` for this game (RP-05).
- No test covers `start=1` player mode, touch progression, the sim floor against `heightAt` in ch1-6, or results totals across chapters. The final results frame was forced with `setMode('done')`.
- The `stepFrames` QA hook takes a fixed input and cannot drive the autopilot, so a deterministic chapter-completion run is not possible on the live loop at 0.07 fps. Let it fall back to `sampleInput()` when no input is given.
- The game has not been run on a real GPU or a real phone.
- RP-04 applies: a typo in `?aura3d-render=` stops the mount. Engine-wide, tracked in the release section.
