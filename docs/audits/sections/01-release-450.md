## 4.5.0 release audit

Scope: `git diff v4.3.7 v4.5.0` plus the post-tag docs and evidence on origin/main 31f8945ad, checked against the 25 live games. No release finding is P0. One is P1: LIGHT-01, a 4.5.0 lighting regression measured on Chroma Roll.

### Dropped on verification

Both release P1 findings were re-checked against the cited code.

- **LIGHT-01 kept at P1.** `compiler/renderer.ts:152` passes `implicitFill: false`. `environment.ts:172-179` then returns preset `authored-lights` with `environmentMapIntensity: 0` and `environmentMapSpecularIntensity: 0` (`explicitLightFillFree`, environment.ts:50-79). `prd02ProbeBindIntensities` (environment.ts:386-392) turns that into 0/0 for the neutral-room probe. All four ports author only `lights.hemisphere` plus `lights.directional`, and rg finds no `environments.*` or `looks.preset` in any of them (heatsink-port/world.ts:101-102, splat-rush-port/backdrop.ts:50-52, strange-orbit-port/world.ts:187-189, saiyan-snake-way-port/world.ts:158-159). The 4.3.7 environment.ts has no `implicitFill` or `authored-lights`. Chroma Roll measured the effect: tower luma 220.4 to 134.1, island underside 189.3 to 94.9, with the custom-shader road as control (151.2 to 150.8).
- **LIGHT-02 downgraded from P1 to P2.** The evidence holds (the steady-state harness covers 10 targets in 5 games), but it is a test gap, not a defect a player sees. The visible parts are LIGHT-01 and LIGHT-03.

No other finding was dropped.

### Render path

Verified correct: under quality `auto` all 25 games take `hdr-msaa`, because each authors an effect, custom material, output option or look (live: Gridlock Courier `bloomFusion: separable`, Chroma Roll `bloomFusion: off`). No live game is on the direct path. When the direct path is used, it keeps r185 ACES plus the sRGB OETF inside the shader (ProgramGenerator.ts:69-94) and applies fog before the encode. `setScene` re-decides the path. `setOutput` warns on the direct path. `preserveDrawingBuffer` follows `?capture`/`?qa`. `app.screenshot()` re-renders when idle. The bloom-fusion gating, the GL error-check cadence, the state-cache memoisation, StructuralMemo and per-instance cull bounds are all correct.

### Lighting

Verified correct: A3D_QR_LIGHTING and A3D_QR_COMPILER are on by default (flags.state.ts:21,45). The live site serves the calibrated look fill (0.85/0.65/1.0 in `guard-BFw69cBA.js`). look-fill-game-composition.test.ts passes 8/8. All 8 contact-shadow games have a shadow-casting key light. Variant switches go through setScene, so the fill-yield rule is recomputed per variant.

### Shadows and instancing

Verified correct: cascade skipping uses the forward pass's own selection function and camera inputs (CascadeUse.ts:42), is recomputed every frame, and is off for per-fragment lookups and quality `production`. Per-instance culling runs only in ForwardPass against its own view-projection, never in depth passes; skinned, morph, custom-shader and `frustumCulled:false` items are excluded, and cull bounds are correct for scaled and rotated instances. The upload skip compares contents, so a typed array changed in place still uploads. Dense depth draws and the shadow proxy stay off on every live game (largest node 900 instances, threshold 1,024; `__A3D_SHADOW_PROXIES__` null live). The VAO index leak fix is in place. PCF tap tiers are opt-in. The PRD-2 visual-regression run's only candidate-only failure also fails on main.
