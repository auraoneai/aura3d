## 17. Serpentine Sky Run (`serpentine-sky-run-port`)

**Live:** https://aura3d.auraone.ai/apps/serpentine-sky-run/ · **Source:** `apps/showcase-serpentine-sky-run-port` · **Genre:** platformer

**State:** The game loads and plays on production. In the Prism cloud browser (SwiftShader software GL, 1440x900, about 0.7 fps), boot showed no errors or failed requests (42 resources). The canvas was never blank: mean luma was 188 on the menu, 182 in a run and 207 in the fall outro. Start, lane change, fall, results and restart (KeyR) all worked. The app folder is a 3-line shim, and the whole game lives in `examples/saiyan-snake-way-port`, which has had no commits since v4.3.7. Overall health is degraded. In 3 of 4 `?manual=1` loads, a single GL error permanently froze the renderer. The browser specs also point at a global name that no longer exists, so most of the game's browser coverage cannot run.

**4.5.0 impact:** The game's source did not change, so every 4.5.0 effect comes from the engine. The render path is `hdr-msaa` on `auto`, with fused bloom (`bloomFusion: separable`). That fusion was never compared against the production chain for this game. The game passes no option that 4.5.0 now ignores, so no OPTION_IGNORED diagnostic fires. The "lights-only scenes get no implicit environment" change applies: `world.ts:158-159` authors only a hemisphere light (1.1) and a sun (2.2), with no `environments.*` and no look preset. On 4.3.7 the neutral-room probe lit the PBR runner and the Meshy props. On 4.5.0 they get only the flat hemisphere mean, and nobody has measured the result. The 120/144 Hz interpolation fix is in place (`main.ts:244-256`). The fix that resizes the canvas after ready also applies. Cascade skip, dense instancing, AO/DoF and the contact-shadow mask do not apply to this game.
