## 11. Bunker Zero (`bunker-zero`)

**Live:** https://aura3d.auraone.ai/apps/showcase-bunker-zero/ · **Source:** `apps/showcase-bunker-zero` · **Genre:** action

**State:** The game loads and plays on production. The Prism probe (SwiftShader software GL, so no perf numbers stand for real GPUs) saw no console errors and no failed requests. Steady-state mean luma was 75.7 (3.5% of pixels below 12, none clipped). Movement, firing, enemy attacks, the HUD and Quick Play reset all worked. Floor 1 is fine, but the sim has run-ending bugs. When the boss summons guards, the floor 6 game logic freezes, so the campaign cannot be finished. All audio and feedback stops after about 17 s of play on any floor. Health: degraded.

**4.5.0 impact:** The game source did not change (`git log v4.3.7..HEAD -- apps/showcase-bunker-zero` is empty), so every change comes from the engine. The hemisphere light now adds to the authored ambient 0.9. LIGHT-03 computes the ambient term rising from 0.592 to 0.845 (x1.43), and a sibling game with the same setup measured +18% luma. Look AO now reads real depth, and `effects.contactShadows` is now a real mask. No one has captured Bunker Zero on 4.3.7 vs 4.5.0, so the size of the shift is unknown. The live render path is `hdr-msaa`, but the engine drops SSAO (`droppedPasses ['ssao']`, `missingInputs ['ssao:normals']`). The game pays for the HDR AO path and gets no AO pixels. Needs a measured capture, and probably a hemisphere or exposure retune.

**Tests and evidence gaps**

- No sim unit tests exist. `tests/unit/bunker-zero/` holds only enemy-facing, weapons-view and local-assets tests. Add `sim.test.ts`: summoned ids resolve to nodes (C1), 200 events produce 200 drains (C2), Kill House timeout gives a lose outcome (C4), per-weapon magazines (C5), enemy rocket falloff (C6), closed doors block LOS (C7), floor 6 winnable with the starting loadout (C14).
- No 4.5.0 capture exists. The final screens date from 2026-10-25 (before 4.3.7 and 4.5.0), the results screen was never reached, and every box in `docs/upgrade-4.5.0/bunker-zero.md` is unchecked (RH-04, RH-05, RH-03, LIGHT-02, LIGHT-06). Run the remote steady-state luma capture on 4.3.7 vs 4.5.0. Also run a separable bloom vs `?aura3d-render=production` diff (RP-05).
- Engine, all createGameApp games: `diagnostics().fps` is hard-wired to 60 (`packages/engine/src/agent-api/app/frameLoop.ts:219` `fps || 60`). The live probe got 60 from it while rAF measured 1.3 fps, and `frame.frames` stayed 0, so frame timing (p50/p95) is empty.
- Engine: SSAO is requested but dropped live (`missingInputs ['ssao:normals']`), so AO adds HDR cost and no pixels.
- Draw calls (210-217 on floor 1, live probe) and triangle counts are not recorded in `evidence/showcase-bunker-zero` (checklist §3).
- The page loads the shared 2.6 MB root asset catalog, in which 522 URLs return 404 (RH-06). Import only the per-app `src/aura-assets.ts`.
- Startup warning "step() was called before the WebGL renderer finished mounting": the first frame renders nothing (engine, P3).
