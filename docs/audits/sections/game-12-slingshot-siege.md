## 12. Slingshot Siege (`slingshot-siege`)

**Live:** https://aura3d.auraone.ai/apps/showcase-slingshot-siege/ · **Source:** `apps/showcase-slingshot-siege` · **Genre:** action

**State:** The game loads and plays on production with no console errors and no failed requests. The live probe ran on SwiftShader software GL at 1440x900. Steady-state mean luma was 111.6 at 3 s and at 12 s, with 3.2% of pixels dark, 0% clipped and about 120 coarse colours, so the frame is lit and not blank. The probe counted 394 draw calls, the highest of the five games probed, and the page ran at about 0.3 fps. Keyboard aim (W) and launch (Space) work, but R, P, M, Tab, Escape and Q do nothing, and the probe found several other player-visible bugs in the game's own code. Health: degraded.

**4.5.0 impact:** 4.5.0 changed only `package.json` (the version bump) in this app, so any effect comes from the engine. The look is `outdoor-day`, which has an HDRI, so the lights-only and no-HDRI fill changes do not apply. The quality profile is `production`, so the cascade skip is off. No instanced node reaches 1,024, so dense depth draws are off. All primitive options are known keys, so nothing raises OPTION_IGNORED. Real-depth AO is on through the look preset and changes the image. Nobody has measured that change for this game (LIGHT-06), and there is no 4.3.7-vs-4.5.0 luma comparison (LIGHT-02). The authored hemisphere light (`stage.ts:145`, 0.4) is dropped because an environment is present. 4.3.7 behaved the same way, so this is not a regression (LIGHT-05). None of the bugs below were introduced in 4.5.0.

**Tests and evidence gaps**

- `apps/showcase-slingshot-siege/tests/smoke.spec.ts` is outside the root vitest `include` (tests/unit, integration, assets, qr), and the app has no test script, so no gate runs it.
- No unit asserts cover pool sizes per level (SS-5) or the material reset (SS-4).
- `evidence/slingshot-siege/screens/final` is dated 2026-10-25, before the 4.5.0 engine changes. It never reached a results screen and records no draw calls, contrary to `new-game-checklist.md:38-40` (RH-05).
- There is no 4.3.7-vs-4.5.0 steady-state luma comparison, no AO-on/off pair and no real-GPU capture (LIGHT-02, LIGHT-06). The 4.5.0 upgrade guide for this game says nothing was rendered (RH-04).
- The hemisphere light at `stage.ts:145` is silently dropped (LIGHT-05). A fix in the engine will brighten this game, so capture before and after.
- The live probe ran on SwiftShader only, so frame-time and draw-call cost on a real GPU are unmeasured.
