### Finding: the cascade shadow never lit the road

`?dbg=shadow` (r2, r3) drew the raw `a3dSunShadowAuto` term on the track: 0 (fully shadowed) on every pixel, with 3 cascades, with 1 near cascade, and with the ribbons not casting. So the painted road and the other `material.custom` surfaces never received the 18-degree key light, and every judge round since phase 2 read "flat, ambient". The engine picks a cascade per draw from the item's world centre (`forward/Lighting.ts` `forwardCenterCascadePosition`), which is wrong for one ribbon spanning the course, but the term stayed 0 with a single cascade too, so the custom-shader shadow receive is suspect on this path. Handed to the engine owner (E-D chunk `a3d_shadow`). Game fix (presentation only): the gouache custom surfaces stop receiving the cascade map (`materials.ts`), `?look=original` keeps it; grounding comes from the rider shadow quads (strength 0.85/0.65 to 0.95/0.8).
