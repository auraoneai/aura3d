## Decisions

1. Genre `platformer` (GAME_GENRES has no exploration genre).
2. Primary visible environment is the painted sky (`background: "sky"`); kloppenheim_06 is IBL-only, so `look-identity` does not hash it as a primary.
3. Sun azimuth WSW (62-70 deg from south toward west) puts the sun behind the follow camera's left shoulder: long shadows reach toward the sea across the frame. Sun disc and god rays are therefore mostly visible in sequences.
4. Reduced flash uses `prefers-reduced-motion` (the page has no separate flash setting).
5. Camera sequences never run with `manual=1` or `start=1`, so existing replay and capture specs see the follow camera.
6. Commit trailer: the Claude co-author line from the session's attribution rule (EXECUTION.md names a Devin trailer).

## Phase-2 visual fix

Base: gu47/integration 22c1283c0 merged. Fix commit `cf5fb59bf` (presentation only, gameplay frozen).

**Problem (recap2 and freeze frames):** every GLB (cottage, oaks, shrubs, traveller, bell frame) drew as a flat cream silhouette in every daylight key, the moonlit epilogue included; the custom-shader meadow, sky and water were clean. The frame read as washed and hazy next to the crisp 4.6.2 frame.

**Diagnosis:** remote A/B capture `g23ab1` (one round; a temporary uncommitted switch turned one feature off per captured variant): default = all GU47 lighting/post features off -> clean; found0 = only `effects.volumetricFog` off -> clean; found2 = IBL off, found3 = shadows off, epilogue = material overrides off -> still cream. The cause is the volumetricFog "golden shafts" stage (density 0.05, godRayDensity per key) on the GU47 engine. The engine fix itself is outside this lane: handoff to E-C, below.

**Fix:** the GU47 look no longer mounts volumetricFog (`SHAFTS_ENABLED = false`; `shaftPatch` kept as the per-key table, the runtime patch is skipped). No shafts were visible anyway (WSW sun behind the follow camera). Grade saturation 1.05 -> 1.14, contrast 1.06 -> 1.1, vignette 0.22 -> 0.16, toward the 4.6.2 colour. Shadows, IBL, hemisphere fill, material overrides, paper pass and grain stay.
