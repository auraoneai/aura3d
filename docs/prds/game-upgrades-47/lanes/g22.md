## Decisions

- One look record per route (`SALTWIND_LOOK`) feeds both the engine nodes and the custom GLSL uniforms; `ORIGINAL_LOOKS` keeps today's numbers for `?look=original`.
- The visible sky stays the custom dome on every route (`background: "sky"`), so the route HDRIs are secondary IBL-only uses and do not count as primary environments for `look-identity`.
- Signal red is the reserved objective colour and the only accent: relay gantry glow, nitro, finish, Halo beacons. The kicker/shortcut ramp glow stays cyan because the in-game hint text names "cyan paths" (gameplay readability, PRD D8).
- Heat shimmer and speed streaks share one custom pass so each route has exactly one shaderPass.
- Slow-mo scales the wall clock of the fixed-step loop (`now`/`schedule` injection), never `SIM_STEP`.
- Reduced flash follows reduced motion (the game has one motion switch).
