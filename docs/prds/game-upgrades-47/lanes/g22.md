## Decisions

- One look record per route (`SALTWIND_LOOK`) feeds both the engine nodes and the custom GLSL uniforms; `ORIGINAL_LOOKS` keeps today's numbers for `?look=original`.
- The visible sky stays the custom dome on every route (`background: "sky"`), so the route HDRIs are secondary IBL-only uses and do not count as primary environments for `look-identity`.
- Signal red is the reserved objective colour and the only accent: relay gantry glow, nitro, finish, Halo beacons. The kicker/shortcut ramp glow stays cyan because the in-game hint text names "cyan paths" (gameplay readability, PRD D8).
- Heat shimmer and speed streaks share one custom pass so each route has exactly one shaderPass.
- Slow-mo scales the wall clock of the fixed-step loop (`now`/`schedule` injection), never `SIM_STEP`.
- Reduced flash follows reduced motion (the game has one motion switch).

### Root cause: no shadow ever reached the road (rubric shadows 3-4 in every earlier round)

Two engine behaviours stacked, both measured:
1. The forward pass picks **one cascade per draw** from the draw's world centre (`selectForwardShadowMap`). The road, flanks and town are each a single custom-shader mesh whose centre is hundreds of metres down the course, so with 3 cascades they sampled the far cascade, which does not contain the car.
2. The default **4.2.0 shadow fit** widens the map to the bounds of every caster. Probe `g22p4-probe` (`d.renderer.shadows.observed.lightMatrix` scale ~5e-5) showed one 2048 map spread over ~30 km, so a car-sized shadow was under one texel.

Fix (game side, public switches): one PCSS cascade over the near 75 m (`art/look.ts` `SHADOW`) plus the 4.3.0 fit `__A3D_SHADOW_FIT__ = "current"` on the GU47 looks (same switch as `examples/ninja-runner-port`; `?shadowfit=legacy` / `?look=original` keep 4.2.0). The car, trees, hoodoos and relay gates now cast readable shadows (`p4-r4` frames). Side effect: draws fell to 129 / 123 / 107 (Sunbreak / Redline / Halo; were 206 / 176 / 140), now under the WP-32 170 budget. Triangles 2.43 M / 1.02 M / 0.66 M. Engine handoff: per-fragment cascade selection for `a3d_shadow` custom receivers would let big custom meshes use 3 cascades.

### Other changes
