## Decisions (autonomous, reversible)

1. **Look key runtime id.** `looks.preset` gives the key light no runtime id, so `apexLookNode()` maps the `"look key light"` child of the preset group and adds `runtime: { id: "apex-sun-key" }` (same node, same look group, `appliedLook` unchanged). Handoff to E-A for a first-class option.
2. **Dome stays the sky; HDRI is IBL only.** `industrial_sunset_puresky` (PRD "belfast or industrial"; belfast is already several games' primary sky) at rotation 205 deg via `background: <colour>` (E-A: HDRI lights, is not drawn). `environment.background: "sky"` in the art direction, so the `look-identity` duplicate check does not count it as a primary sky.
3. **Practicals = 6.** The PRD asks for 6 sodium spots + 2 headlights + a tail point plus a fill, which breaks C-35's 6-practical cap and Low's 4 lights per pixel. Kept: fill + 3 sodium spots + 2 headlights. The tail-light read comes from the brake bars and the emissive tail gain.
4. **Sound walls became parapet rails.** The 2.5 m walls hid the drop to the haze floor (the line of sight over a 2.5 m wall at 11.6 m reaches y -28 only 330 m out); rails on the Jersey barriers make the skyway read as elevated. Runtime ids kept.
5. **Procedural towers replace the borrowed skyline now.** The skyline is set dressing, not a hero subject, and the borrowed 75-mesh townhouse model contradicts the identity and costs 72 draws more than the 3-draw instanced towers. The Meshy kit drops in per variant (`TOWER_VARIANTS`, render/towers.ts).
6. **Trim colours.** Row text "amber/cyan": left trim identity cyan (sky-lane side), right trim sodium amber; the magenta trim, dusk stops and the purple magnet colour (scene + HUD swatch) are gone.
7. **Quick bar no longer writes the sim.** The old time-of-day buttons called `world.setTimeOfDay`; now they only pin the presented time of day (`manualTodOverride`), like `?tod=`.
8. **Slow-mo is a clock scale.** `simClockMs += realDt * scale`; the fixed-step sim runs the same steps later (reference replays unchanged).
9. **Contact disc removed** in favour of `effects.contactShadows` + 3 sun cascades (AO-L4).

Apex Overdrive: "Blue-hour skyway".
