## Decisions

1. No `workbench-night` look exists in E-A's merged set, so DD47-E1 is hand-built (no `looks.preset`): a look preset
   always emits a shadowed directional key, which would be a second shadow caster next to the desk-lamp spot.
2. `?look=original` is not added: dot-dash-3d is an app game, not a port, and E-I's targets for it are `?maze=` only.
3. Glowing materials that are light sources in the fiction (LED lenses, vents, lit traces, gems, halo, door, beam) are
   `practical: true`; the board, chips, pins and sentries carry no emissive at all, so the audit's `emissive-fill`
   rule is clean.
4. The trace signature uses an instanced overlay pool rather than a `material.custom` slab: one extra draw, no texture
   memory, and it works with the merged E-D instance-colour targets; the baked maps remain the M1 follow-up.
5. The run intro plays only when `score === 0 && dotsEaten === 0 && boardsCleared === 0`, because respawns also pass
   through READY.
6. Gameplay is untouched (PRD D8): every new value reads `st` (mode, positions, events) and nothing writes it;
   `sim.test.ts` (19 tests) passes before and after.
