## Decisions

- Default view is the shift look; `?look=original` is the 4.6.1 path unchanged (kloppenheim_06 tinted `#ffc890`, hemisphere fill, 2 cascades, peach dome).
- `?at=N` pins only the time-of-day clock (`todSeconds`). The shift clock, jobs, score and the QA replay surface never read it. A shift shorter than 180 s (`?shift=`) is scaled onto the 180 s clock.
- No hemisphere next to the HDRI in the shift look: the IBL is the fill (PRD §3.2 "fill: environment"), and C-35 counts the hemisphere as a practical.
- Commit trailer: these commits carry the Claude co-author line (the agent that wrote them), not the trailer in EXECUTION.md.

## Run 2 decisions

- GC-C1 adds an `intro` game phase: `isActive` and `stepShift` only run in `playing`, so the shift clock, jobs and replays start when the intro ends; `autostart=1`, `manual=1`, `stepFrames` and reduced motion never enter it.
- GC-AN1 body order: the courier model uses `rotationOrder: "YXZ"` in the shift look only (pitch and roll about the car's own axes); the original look keeps ZYX.
- Brake read: `TrafficCar.v < speed - 0.6` (both written by `stepTraffic`), no sim flag added.
- GC-S5 and GC-P3 are High-only post nodes toggled through `post.setEffect(..., { enabled })`; whether `setEffect` honours `enabled` for `volumetricFog` / `depthOfField` is a phase-2 stage-list check (E-C).

## Run 3 decisions

- GC-H1 ships behind `body.dispatch` (set by `main.ts` in the shift look), so `?look=original` keeps the 4.6.1 HUD byte for byte. The DELIVERED popup becomes the stamp in the shift look; the other popups stay.
- GC-L5 flare: `lights.lensFlare` cannot be occluded by geometry, so it is hidden unless the eye is ahead of the car (`FLARE.minFacing` 0.25) and the beams are on. The handle starts visible and the first `placeFlare(null)` hides it before the first `app.step`.
- GC-C1 side shot reads `shift.deliveries` (read only) on the delivered event; it overrides the chase pose after `placeNodes`, so the chase rig state keeps tracking underneath and the hand-back is the rig's own pose.
- GC-H2: 3 banners rather than 4 districts plus street plates, to stay inside the row's +6 draws.
- GC-S4 stays on the custom harbour shader although E-G now exports `world.water`: the shader already carries the glitter path and quay foam the row asks for, and a swap is a look change with no capture to check it in phase 1.
