# Lane g03 (G03, WP-13): Thermal Drift (heatsink), "Foundry megacity seen through heat"

Branch `gu47/g03`, base `50eee4ba2` (gu47/integration, engine lanes merged), wave 2 (phase 1, code). Status: in progress (see rows).

App `apps/showcase-heatsink`; tests `tests/unit/heatsink/`; evidence `evidence/game-upgrades-47/heatsink/`, `evidence/thermal-drift/`.

## Decisions

- **Circuit change remounts the scene** (HS-03): sky, rig, fog, post, skyline and weather all differ per circuit, so `selectCircuit` calls `setScene(buildThermalDriftScene(...))` and rebinds every handle (the E-H GLB cache makes the second mount fetch-free). E-B runtime calls are kept for what changes inside a race (HS-16 sector cross-fades, HS-12 boost blur). `applyCircuitLook` (recolour of 8 nodes) is gone.
- **Hand-built rig instead of a look preset** (HS-01): `night-city` is replaced by authored nodes (one PCSS 3-cascade key, unshadowed cyan rim, VESPER up-fill, explicit AO, the circuit HDRI with background on, fog, grade with exposure, bloom, vignette, grain), so every WP number is visible in `src/look.ts` and the authored scene; the art-direction audit reads the real lights and the `hdri` environment.
- **Sky, key and skyline stay fixed in the view frame** (HS-04): the world scrolls past a drone that always faces -Z; rotating the HDRI and skyline with the integrated track heading would also need a per-frame key `setLight({ direction })` that could fight the 1.5 s sector cross-fade. Parallax comes from the chase camera's lateral travel; heading-coupled rotation is a possible follow-up.
- **Player heat reads as an attached exhaust plume, not a ribbon** (HS-13): a trail ribbon on a drone that barely moves in view space would be a few centimetres long; only the missiles (which travel in view space) draw `effects.trail` ribbons.
- **Textures as WebP** (HS-07): the repo `.gitignore` drops `*.jpg`/`*.png` outside listed paths; WebP is a supported texture format and not ignored.
- **HS-14 does not exist** in the PRD table (the ids jump from HS-13 to HS-15).
