## Decisions

- Run 2: every new effect is script-mode only; `?look=original` keeps the old streak boxes, `playClip`, chase camera and HUD.
- SSR-15's intro plays for the first 4 s of run time (`S.time`); E-I's stage rows step 360 frames (6 s) so captures land on the chase shot. A capture at `S.time < 4` shows the intro.
- SSR-14's mixer steps `dt x rate` so the base clip keeps the old speed-scaled cadence; the hit layer runs at `1 / rate` so it plays in real time.

- The sun's azimuth is relative to the smoothed chase-camera forward, not world space, so "low sun ahead" holds on every bend of the road (the road yaws through several full turns).
- The hemisphere stays a hemisphere light (not ambient); the audit snapshot lists it with the sun and fill.
- `?look=original` is implemented by keeping the old scene graph and shading (lookMode 0), so the "before" look needs no 4.6.0 checkout.
- Primary visible environment is the custom sky (no HDRI), so `look-identity` has nothing to hash for this game.
