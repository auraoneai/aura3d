# Lane g05 (WP-15 iron-crown, "The Royal Forge")

Branch `gu47/g05`, base `232570e41` (wave 1 predecessor commits f9e3a8eb5, 07c9d28ca, 545ea47c7), merged with `gu47/integration` at f27b4d7d7 (all engine lanes plus eint) and again at the start of run 2 (EB-3 multi-caster local shadows). Wave 2, runs 1 and 2 of up to 3. Phase 1 (code) only.

Decisions:
- The uncommitted wave-1 box reflection probe was dropped: `probes` is not exported from the `@aura3d/engine` root (it is undefined at runtime through the root import) and the runtime does not consume reflection-probe nodes (only the C-09 environment probe). The rest of that work (floor finish from the look row, instanced deck, `role: "primaryWorld"` props) was kept and committed.
- C1 shots play inside the existing phase windows (intro 1.35 s, K.O. 1.7 s, bout end) instead of lengthening the intro: the phase timer is part of the round state machine (PRD D8). The acceptance "intro <= 4.0 s" holds; longer shots need an owner decision on intro pacing.
- Letterbox bars are app-local DOM strips: the engine's `createCinematicBarsLayer` is not on the root and cannot reopen after `release()`.
- Run 2: `assets add` regenerates the whole `src/aura-assets.ts` and the current typegen rewrites the fighters' `animations` metadata shape (string list to clip records). To keep fighter clip lookup byte-identical, only the new entries (4 LUTs, the scorch texture) were spliced into the committed file; a full typegen refresh is an owner/E-I call.
- Run 2: PNG and JPG are gitignored repo-wide, so the generated scorch and the CC0 floor maps ship as webp (the K.O. scorch lossless). Lane g22's slingshot-siege CC0 JPGs (7c4252c1f) were not committed for this reason (PROVENANCE.md only); noted for that lane.
- Run 2: `resolveTypedFighterAssets` now takes any typed asset map and keeps only `model` entries, since the manifest also carries `lut` and `texture` entries.
- Run 2, IC47-E4 declined: E1's six HDRIs already draw every outdoor sky (no solid void); a Preetham or gradient sky would replace those distinct skies. Needs an owner call to trade one for the other.
- Commit trailer: `Co-Authored-By: Claude <noreply@anthropic.com>` (the session's attribution rule) instead of EXECUTION.md's Devin trailer used by the wave-1 commits.
