# Aura3D 2.0 clean-environment reproduction

Date: 2026-08-12
Source commit: `c1cf266bb2c784bdd4ccbff0ceb375c38473cb43`
Host result: pass
Clean Linux container result: pass with an explicit native-WebGPU hardware boundary

## Scope

The release candidate was copied from a clean local clone into the official
Playwright `v1.59.1-noble` Linux image. The container had no host `node_modules`,
package-manager cache, generated `dist`, global Aura3D installation, npm
credential, or checked-out report directory. It used the repository-locked
`pnpm@11.1.3` and a frozen lockfile.

The clean profile completed:

- frozen installation of all 31 workspace projects and 442 lockfile entries;
- the complete TypeScript build graph;
- all 63 `tests/unit/aura3d-cli/assets.test.ts` checks, including lean typed-asset
  generation;
- production build/finalization for all 29 public packages;
- packing all 29 version-`2.0.0` tarballs;
- npm installation of those tarballs into the isolated comparison consumer;
- 23 of the 24 current head-to-head browser assertions, covering every WebGL2,
  glTF, material/shader, postprocess, Rapier, Recast, resource-lifecycle,
  scaffold/deploy, and injected-session XR assertion available without native
  GPU passthrough.

The sole container-only failure was the native WebGPU/TSL render assertion:
Chromium's software container profile returned no WebGPU adapter. The exact
same installed-tarball assertion passes on the source host's hardware-backed
Chrome, where all 24/24 assertions and all 15/15 workloads pass. This result is
therefore a clean-machine reproducibility receipt with a declared hardware
boundary; it is not a claim that a GPU-less Linux container proves native
WebGPU.

## Reproduction recipe

From a clean clone at the source commit, copy the checkout into the exact
Playwright image (copying avoids Docker Desktop host-path sharing assumptions),
then run:

```bash
git config --global --add safe.directory /work
corepack enable
corepack prepare pnpm@11.1.3 --activate
pnpm install --frozen-lockfile
pnpm typecheck:raw
pnpm exec vitest run tests/unit/aura3d-cli/assets.test.ts --reporter=dot
pnpm head-to-head:installed
```

Container image:

```text
mcr.microsoft.com/playwright:v1.59.1-noble
sha256:b0ab6f3cb99aa7803adbc14d9027ec1785fc6e433b97e134e0f8fe61683b6b53
```

For the native WebGPU row, rerun the same final command on a machine/browser
profile with a real WebGPU adapter. Do not replace that row with a mock adapter
or count software-renderer absence as engine evidence.
