`uniqueOwnership.ts`; `pnpm check:public-surface-diff` now enforces a real

Tool fixes needed to make the gate honest:

- `localModule` resolves `@aura3d/*` specifiers via `aura.exports.json`
  (cwd only — the baseline archive predates the map). Without it every
  deprecated stub surface read as empty → 3,449 phantom removals.
- `sourceForTarget` expands wildcard exports (`./contracts/*`) to the union
  of matched `src` files.
- `setLocal` keeps a runtime kind when a name is declared as both a value
  and a type (`const A3DRenderer = Renderer; type A3DRenderer = Renderer`),
  so `export { name }` isn't misread as type-only.
- New classifications: `documented-prd15-6.1-root-collapse-…` (verified
  against the deprecated-subpath symbol union) and
  `documented-prd15-t2-t4-production-effects-and-parity-contracts-deleted`
  (the 6 `ProductionEffects*`/`RuntimeParity*` names whose source files were
  deleted in T2.2/T4 — `git log` verified).

## Cross-cutting: ESM cycle repair (needed for the packed dist to import)

The T3 leaf split left ~90 real modules forming one **87-file SCC**
(Tarjan). Aggregates (`game`, `prefabs`, `gameRules`, …) mutually embed each
other's const exports → eval-time `Cannot access 'X' before initialization`
under native ESM (bundlers masked it). Fix:
`packages/engine/src/agent-api/lazyNamespace.ts` — a zero-import Proxy
(`lazyNamespace`/`lazyCallable`) that defers the aggregate literal to first
property access, forwarding all introspection traps. 24 initializers
wrapped. Member identity preserved (`game.rules === gameRules`),
enumeration/spread/`JSON.stringify` verified, builder chains work. Covers
cross-lane files — documented in `requests/Q-ALL-2` + the ten repoint
requests (Q-02-1, Q-03-1, Q-04-2, Q-06-1, Q-07-2, Q-08-1, Q-09-2, Q-10-1,
Q-11-2, Q-13-8) now marked APPLIED BY LANE 15.
