## 4. PBRLightingDefaults 0.18

[PBRLightingDefaults.ts](/Users/gurbakshchahal/platforms/aura3d/packages/rendering/src/PBRLightingDefaults.ts:3) is a *material-constructor* default for `u_environmentIntensity` in five classes (PBRMaterial.ts:137, TexturedPBRMaterial.ts:463, InstancedPBRMaterial.ts:72, SkinnedLitMaterial.ts:173, NormalMappedPBRMaterial.ts:76), publicly exported (index.ts:604), plus the glTF missing-material fallback (GLTFRenderResources.ts:1965, :1971). The production engine path never uses it — primitives pass an explicit `envMapIntensity ?? 0.75` (floor 0.35 with extensions, primitives.ts:303–306) — and on any Renderer path with scene environment lighting it is overwritten per draw (ForwardPass.ts:1242); it survives only for `Scene`/iterable sources (Background.ts:99 returns undefined) or direct ForwardPass use.
