# Aura3D 2.0.1 Release Notes

Version: 2.0.1

Status: published to npm and GitHub on 2026-08-14; canonical website
publication is verified as a separate go-live step

Aura3D 2.0.1 is a coordinated patch release across all 29 public packages. It
retains the 2.0 public architecture and claim boundaries while correcting
visible vehicle-to-vehicle contact in Turbo Drift Circuit, strengthening
clean-build package finalization, and removing internal planning artifacts from
the public documentation surface.

## Vehicle-contact correction

Turbo Drift Circuit now uses Rapier-oriented boxes derived from the fitted
rendered footprints of both Formula vehicles. Rapier owns solid contact and its
solved X/Z positions feed back into the arcade racing state before chassis
grounding and rendering.

A direct rear impact now has a bounded, visible response:

- the striking car loses momentum;
- momentum transfers into the struck car;
- a short hit-stop preserves the readable contact moment;
- both cars receive opposite yaw responses;
- the cars separate after impact instead of stacking or moving as one body;
- no decorative collision geometry or screen-space effect substitutes for
  physical contact.

The retained browser producer captures approach, exact first contact, immediate
reaction, and separation. The accepted first-contact run records one impact
response, zero Rapier penetration, a 0.001-unit rendered-envelope clearance,
and measurable momentum transfer. The proof is generated by
`tests/browser/turbo-vehicle-grounding.spec.ts` and recorded under
`tests/reports/turbo-vehicle-grounding/`.

## Package integrity

Root compatibility exports for `@aura3d/engine/lean`, `/lean-game`, and
`/lean-product` are internalized into the broad engine tarball. Dist
finalization now copies every workspace package before rewriting cross-package
imports, so a fresh checkout produces the same independently installable root
package as a warm development workspace.

The release inventory remains 29 public packages in lockstep at `2.0.1`.
Package publication is performed in dependency order through
`tools/release/publish-all.mjs`, followed by direct npm registry readback for
every exact version.

## Documentation and repository surface

Internal PRD, handoff, implementation-plan, and roadmap Markdown files were
removed from the public repository surface. The Markdown audit now rejects
those artifact classes and accepts only retained developer, API, operational,
release, and evidence documentation.

## Install

```sh
npx create-aura3d@2.0.1 my-scene --template product-viewer
npm install @aura3d/lean@2.0.1
```

Use `@aura3d/lean/product` for typed product scenes and
`@aura3d/lean/game` for deterministic arcade motion. Use
`@aura3d/engine@2.0.1` when an application intentionally needs the broader
compatibility-heavy safe authoring surface.

## Superseded release

Version `2.0.0` remains available for reproducibility but is superseded by
`2.0.1`. All 29 npm versions are deprecated with an upgrade notice, and all 29
public packages report `2.0.1` as `latest`. The immutable `v2.0.0` Git tag and
historical release notes remain intact.

## Claim boundary

This patch does not broaden Aura3D into a universal Three.js replacement or a
physical motorsport simulator. Current Three.js comparisons remain limited to
the named repository-locked `three@0.185.1` workloads, and Turbo Drift Circuit
remains a bounded arcade-handling presentation with Rapier contact ownership.
