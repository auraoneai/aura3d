# Aura3D Deployment Rollback Plan

Version: 2.0.2

Aura3D has two public deployment tracks:

- **Canonical product site:** Vercel project `marketing`, branded as
  `https://aura3d.auraone.ai`. This serves the marketing site, docs, showcase library,
  public app routes, and promoted Aura Clash routes.
- **Secondary static demo:** GitHub Pages through
  `.github/workflows/public-demo-deploy.yml`. That workflow deploys the static
  external demos generated by `pnpm build:external-demos`; it is not the canonical
  branded production target.

## Rollback Rules

1. Keep the previous package artifact or hosted demo build available until the new one has passed smoke checks.
2. Verify the public URL or package install path, not just the local dev server.
3. If a deployment report, route health report, screenshot, or package smoke report fails, roll back to the last known passing artifact.
4. Update public docs only after the deployed artifact and docs point to the same version and evidence.

## Vercel Alias Rollback

Before changing the alias, confirm that the retained deployment is Ready and that its
home page and representative showcase route return HTTP 200. Then run:

```bash
vercel alias set https://marketing-1qwdo8x3c-veerone.vercel.app aura3d.auraone.ai --scope veerone
```

Verify the rollback:

```bash
curl -fsSIL https://aura3d.auraone.ai/
curl -fsSIL https://aura3d.auraone.ai/apps/showcase-index/
curl -fsSIL https://aura3d.auraone.ai/playable
```

The rollback is complete only when the branded alias resolves to the retained
deployment, all three routes return HTTP 200, TLS remains valid, and the deployed
visual proof passes. Restore the current production deployment with the same
`vercel alias set` command using
`https://marketing-1q5qqbfdf-veerone.vercel.app`.

## Evidence Requirements

Deployment evidence should include:

- package version;
- git revision;
- build command;
- URL or package artifact path;
- smoke-test command and result;
- known unsupported browsers/devices.

For the GitHub Pages external demo workflow, evidence should also include the generated `public-deployment-manifest.json`, `static-integrity-manifest.json`, `deployment-command-plan.json`, and a passing `pnpm verify:public-demo-deployment` result for `A3D_PUBLIC_DEMO_URL`.

The canonical 2026-07-23 Vercel evidence bundle is stored under
`docs/project/production-evidence/2026-07-23/`. Local examples and local static
exports are not public deployment evidence by themselves.
