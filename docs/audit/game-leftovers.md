Date: 2026-10-24. Scope: the 15 index games (`apps/showcase-<slug>`), the 11 `examples/*-port`, `apps/showcase-port-shared`, and the four starter templates. Method: semantic scan (`rg` by behaviour, not by the word "workaround") plus reading each hit. Chase cameras, objective markers and the toon pass are excluded: `promote-cameras`, `promote-marker` and the toon promotion own them.

Verified clean across all 26 games: no GLTFLoader or hand-rolled hash tables, no own black-frame guard implementation, no own diagnostics panel, no vendored engine bundles. The shared `blackframe.ts` and `diag.ts` wrappers are thin passes over `@aura3d/debug`.

## Group B migration (Silt & Signal, Ninja Runner, Last Train, Roadster Hours)

Done: F2 (QA hook) and F3 (fixed-step loop) for these four ports; F4 (audio) deliberately not done.

- **F2:** each port now installs its hook through `installQaHooks`; every existing member is kept as `extras` (specs and evidence scripts read them by name). The kit now preserves getters in `extras` (`get ready()`, `get state()` stay live), which the ports' specs rely on (`__AURA_SILT__.ready === true`). The first-error global goes through `reportError`.
- **Iron Crown roster faces (art pass, closed 2026-10-25):** Boulder, Seraph and Sovereign carried photographic atlas faces; `flatface.mjs` (options `skinOnlyHead`, `keepLight`, `flattenAtlas`, `faceExtra`) replaced them with flat stylised faces, evidence in `apps/showcase-iron-crown/aura-evidence/restyle/*.flatface.json` and `evidence/iron-crown/rework/p1-roster/`. Jinx keeps his painted mask. Gameplay, hitboxes and clips are untouched; software-GL frames only, not real-GPU evidence.
- **F3:** each live loop is `createFixedStepLoop` with the port's own step, clamp and catch-up cap. `tests/unit/port-kit-migration/fixed-step-equivalence.test.ts` compares steps per frame against the old accumulator on 20,000 seeded frames per configuration (whole-millisecond frames, so the doubles are identical): all equal. `stepFrames`, `replay` and the other manual paths still call the sim directly, so replay traces are untouched. Restart calls `loop.resetAccumulator()`.
- **Small live-loop differences (not covered by replay):** the clock drains in non-play screens instead of freezing (steps are skipped there), so resuming never bursts; Ninja and Roadster run countdown, audio and render after the steps in a frame instead of before; Last Train no longer takes a 0.1 s burst on its first frame; Silt's `renderTime` starts at ready instead of at load.
- **F4 not done, per port:** the audio files mix one-shot cues with continuous, per-frame driven voices (Silt pad, hum and wind; Ninja wind and music bus; Last Train wind, rumble, hiss, squeal, pad; Roadster engine pair, wind, music). `createCueBank` covers the one-shots only. Silt's chimes use a linear attack ramp (the bank is exponential); Ninja's and Roadster's noise hits start at a `Math.random()` buffer offset (the bank uses a fixed LCG buffer). Moving only the one-shots would split mute, unlock and master gain across two audio graphs. Needs a library driven-voice API (named loops with per-frame targets) plus an offline automation-recording comparison before any port moves; audible parity cannot be judged here.

## Port kit migration (lane pckits, 2026-10-25)

Method: every move has a unit test that compares against the code it replaced (golden captured or reference copied before the change). `node tools/game-checks/run.mjs --all` before and after: 26 games, 0 errors, the same 5 Meshy cap warnings. Nobody listened to any audio change.

**Model loader (closed for 10 tables).** Splat Rush, Drift and Deliver, HEATSINK, Cloud Runner (`models.ts`), Last Train, Ninja Runner props, Serpentine Sky Run, Strange Orbit, Where the Wind Wanders and Silt and Signal (models only) use `defineModelAssets`. `tests/unit/port-kit-migration/model-assets-equivalence.test.ts` compares every ref (URL, hash, format, bounds, size, metadata) with a golden captured from the hand-written tables; the only normalisation is Strange Orbit's redundant `sha256` field next to an equal `hash`. Not moved, and why:
- Strange Orbit `ROCK_ASSET` and Last Train `windmill`/`tower` use `new URL(...).href`; the library would turn that into a pathname in the browser, a URL change nobody has checked.
- Drift `params.get("models") !== "0"` stays: the library predicate also switches models off for `false`, `off` and `no`. Last Train `?procedural=1` is a different parameter with the opposite sense.
- Textures-only or binary-geometry tables (Cloud Runner and Drift `ASSETS`, Roadster Hours `meshy.baked.ts`), Ninja `CHARACTER_URLS` (raw URLs for `cloneSkinned`), and the index games' `aura-assets*.ts` (generated by `assets typegen`) are not hand-rolled GLB tables. Roadster Rush already used `defineModelAssets`.

**Scatter planner (not migrated; kept the old placement).** Cumulus Dash mesas: the planner draws in exactly the loop's order and kind, yaw, position and height are bit-identical (`scatter-equivalence.test.ts`), but the planner draws `min + r * (max - min)` and `1.7 - 0.8` is 0.8999999999999999, not the loop's literal 0.9 (no `max` gives exactly 0.9), so scale and every merged vertex differ in the last digit. Fixing it needs a span option on the planner's public surface. Other placement code is not planner-shaped: Drift `props.ts` has no randomness (it reads the city layout), Cloud Runner `buildScatter` and `buildClouds` interleave draws across five object kinds with mode-dependent counts, Ninja scenery changes its draw count with the models flag, HEATSINK `sceneryNodes` reuses one draw as the category selector, Last Train and Where the Wind Wanders pass the stream into mesh builders. `geometry.mergeStatic` merges scene nodes, not the hand-built vertex-colour `Mesh` buffers, so its output is not identical.

**Safety net (closed).** Deleted `apps/showcase-port-shared/blackframe.ts` and `examples/drift-and-deliver-port/blackframe.ts`. The 14 index games and the Aura Slam original adapter import `installBlackFrameGuard` from `@aura3d/debug`; Drift imports `createBlackFrameWatch`, `healParams` and `healStage` from it and keeps its own storage key. Their tests moved to `tests/unit/debug-safety/qr-heal-ladder.test.ts` and `heal-ladder.test.ts` (they covered library behaviour nothing else did). `apps/showcase-port-shared/diag.ts` stays: it already calls `installSafetyNet` and only adapts each port's QA hook to the panel.

**Audio (partly closed).** On `createCueBank`, each with a parameter-level test (oscillator types, start times, gain envelopes, glides): all 11 Roadster Hours effects (also noise filters, Q, stop times and noise samples), the 7 Last Train event cues, Ninja Runner `pickup`, `unlock`, `win`, `lose`, `warn`, and 13 Strange Orbit tone cues. Known differences: the kit stops tone voices 20 ms earlier than the old code (after the envelope reached 0.0001); Strange Orbit tones no longer pass through its compressor, and each port's bank adds a second master and sfx gain pair summed at the destination (same total gain). Left hand-written: noise events in Ninja Runner and Strange Orbit (random buffer offsets, per-hit buffers), Last Train clacks, Ninja `click` (fires on the unlock tick, and the bank drops cues until its context runs), Silt and Signal chimes (linear attack from zero, a different envelope shape), Where the Wind Wanders (a stereo panner per voice, glide over 0.8 of the decay; the kit has no pan), and every continuous voice (pads, hum, wind, engine, music sequencers).

**Remote smoke (software WebGL2, runs `pckits-base` and `pckits-after`, `tests/browser/pckits-smoke.spec.ts`).** Eight ports (Drift and Deliver, Last Train, Ninja Runner, Strange Orbit, Splat Rush, Where the Wind Wanders, Roadster Hours, Silt and Signal) boot, take a gesture that builds the audio graph, and report 0 console errors, 0 page errors and 0 HTTP errors on both trees. Median GL draw calls per frame are equal on both trees before the gesture for all eight and after it for seven; Splat Rush differs after the gesture (98 versus 96), which is live gameplay timing, not scene content. Frame counts are small because of the CPU rasteriser.
