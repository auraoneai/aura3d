# Aura3D error and warning codes

Single source for the `explain_error` tool of `@aura3d/mcp` (and for any other agent-loop table). One row per code: `| code | kind | cause | fix |`. Keep each cell on one line; keep the codes verbatim as they appear in console output, `error.code`, `error.name` or `app.diagnostics()`.

| Code | Kind | Cause | Fix |
| --- | --- | --- | --- |
| RENDERER_MOUNT_FAILED | error (console, `app.diagnostics().errors`) | The production renderer threw while mounting (device lost, a Git LFS pointer file served in place of a GLB/HDR, a missing or hashless asset, a failed pass setup). Nothing draws; the page can still look healthy and non-strict `ready()` can resolve. | Await `app.ready()`, read `app.diagnostics().errors`, pass `strict: true` so `ready()` rejects, check every GLB/HDR is real bytes (not a ~130-byte `version https://git-lfs` stub), keep a fallback, and capture a real frame before calling it done. |
| CONTACT_SHADOW_DEGRADED | warning (console, once) | The contact shadow mask cannot run on this device or frame (missing sampleable depth or a pass setup problem). The mask is skipped; the scene still draws. | No code change is required for a correct frame. Remove contact shadows (`effects.contactShadows` / the look preset option) if the warning is unacceptable on your target devices. |
| CONTACT_SHADOW_PARTIAL | warning (console, once) | Some contact-shadow participants (for example masked, blended or special-material meshes) are outside the contact shadow depth and receive the mask of the surface behind them. | Expected for those meshes. Move the affected meshes out of the participant set, or accept the approximation; do not claim exact contact shadows for them. |
| TEXTURE_FLIPY_DEGRADED | warning (console, once) | An `ImageBitmap` texture was created with `flipY`; WebGL cannot flip it at upload, so it is uploaded unflipped and appears upside down. | Orient the source image when creating the bitmap (`createImageBitmap(..., { imageOrientation: "flipY" })`) or pre-flip the file, and do not rely on `flipY` for bitmap textures. |
| TRANSMISSION_DEGRADED | warning (console, once) | A material needs a transmission lobe and a frame capture that the selected program lacks; it draws without transmission (opaque-looking glass). | Use a plain translucent `opacity` material for glass, or a program/preset that supports transmission, and verify the look in a captured frame. |
| DIFFUSE_TRANSMISSION_DEGRADED | warning (console, once) | A material needs a diffuse-transmission lobe the program lacks; it draws without it. | Drop the diffuse-transmission input (thin translucent leaves, wax) and approximate with colour and opacity. |
| DEPTH_ALPHA_HASH_DEGRADED | warning (console, once) | A blended shadow caster uses alpha-hashed depth, which is not implemented; it casts as an opaque caster. | Use alpha-test (`alphaCutoff`) for foliage and fences, or disable shadow casting for the blended mesh. |
| DEPTH_ALPHA_MASK_DEGRADED | warning (console, once) | A masked material uses a depth contract this device cannot reproduce; it casts as an opaque caster in depth and shadow passes. | Same as DEPTH_ALPHA_HASH_DEGRADED: simplify the mask, or turn off shadow casting for that mesh. |
| DEPTH_ALPHA_COVERAGE_DEGRADED | warning (console, once) | A material uses alpha-to-coverage; its depth and shadow pass uses the alpha-test cutoff instead. | Set a sensible `alphaCutoff`; expect hard-edged shadows rather than coverage-antialiased ones. |
| SCENE_CLIPPING_CONTRIBUTOR_DEGRADED | warning (console, once) | Scene clipping clips the scene's own geometry and shadows; geometry owned by contributors (effects, water, terrain) is not clipped. | Do not rely on scene clipping to cut water, terrain or effect geometry; model the cut in the geometry itself. |
| KTX2_CSP_BLOCKED | error (`AssetDecoderUnavailable`, `error.code`) | The Basis/KTX2 transcoder worker needs `eval`/`new Function` to start and the page Content Security Policy refused it (no `script-src 'unsafe-eval'`). | Add `'unsafe-eval'` (plus `'wasm-unsafe-eval'`) to `script-src` on pages that load KTX2 textures, or ship PNG/JPEG textures only on strict-CSP pages. Draco and Meshopt geometry do not need it. See `docs/assets/decoder-deployment.md`. |
| CAMERA_INFINITE_FAR_UNSUPPORTED | error (`RangeError`, `error.code`) | A production camera was given an infinite (or non-finite) far plane. Production cameras require finite far clipping with the reversed depth mode. | Give `camera.*` a large finite `far` (for example 5000) and keep `near` greater than zero. |
| DEPTH_POSTPROCESS_UNSUPPORTED | error (`RenderDeviceError`, `error.code`) | A depth-aware postprocess (depth of field, SSAO, SSR, contact shadows) was requested on a backend with no sampleable depth texture render targets. | Remove the depth-aware effect for that backend or fall back to WebGL2 with depth texture support; check `app.diagnostics()` for the reported backend. |
| DEPTH_MODE_UNSUPPORTED | error (`RangeError` prefix) | The requested camera depth mode is not supported by the production renderer. It appears as the prefix of CAMERA_INFINITE_FAR_UNSUPPORTED. | Use finite far clipping with depth mode "reversed" as the message says. |
| AssetIntegrityError | error (`error.name`) | A fetched asset failed SHA-256 verification: wrong or malformed hash, missing dependency integrity metadata, or no SubtleCrypto (non-secure context). Never retried. | Regenerate the typed manifest (`aura3d assets add` / `assets typegen`), or run `shasum -a 256 <file>` and fix the hash; serve over HTTPS or localhost; re-stage the real file if a stub was served. |
| AssetPolicyError | error (`error.name`) | An asset URL or format was refused by the loader policy (cross-origin without provenance, unsupported image format for dimension preflight). Never retried. | Keep files under `public/aura-assets/` on the same origin, use png/jpg/webp/ktx2, and keep typed `assets.*` references. |
| AssetSizeError | error (`error.name`) | An asset exceeded the loader size or texture budget. Never retried. | Compress the asset (`aura3d assets inspect` shows sizes), use KTX2 or smaller textures, decimate the mesh, or split the scene. |
| AssetDecoderUnavailable | error (`error.name`) | A compressed asset needs a decoder (Draco, Meshopt, KTX2) that is not registered or could not start. It never falls back silently. | Register the decoders the template ships (`decoders` option), serve the decoder files, and see KTX2_CSP_BLOCKED when a CSP is involved. |
| missing-canvas | error (`AuraRuntimeError.code`) | The selector passed to `createAuraApp` matched nothing, or there is no `document` (SSR). | Add `<canvas id="app"></canvas>` or pass an `HTMLCanvasElement`; create the app in the browser only. |
| missing-asset | error (`AuraRuntimeError.code`) | An asset id has no typed definition. | `aura3d assets add ./file.glb --name x`, import the generated `assets`, then `aura3d assets validate`. |
| failed-glb-load | error (`AuraRuntimeError.code`) | A GLB could not load (404, LFS stub, wrong hash, decoder missing). | Check `app.diagnostics().assets` for the load state, re-stage the real file, run `aura3d assets validate`. |
| unsupported-texture | error (`AuraRuntimeError.code`) | Bad `texture.data` size/format, or a texture type outside png, jpg, jpeg, webp, ktx2. | Match byte length to width x height x channels; convert other formats. |
| invalid-scene-options | error (`AuraRuntimeError.code`) | `scene(init)` got a key it does not understand. It accepts only `children`, `background`, `camera`, `timeline`, `diagnostics`. | Put nodes in `.add(...)` or pass `{ children: [...] }`. |
| invalid-primitive-params | error (`AuraRuntimeError.code`) | A `params` key has no effect on this primitive kind; only segment-style keys are accepted. | Use `size` / `scale` for dimensions and the supported segment key named in the message. |
| invalid-model-assets | error (`AuraRuntimeError.code`) | `defineModelAssets` needs a 64-character hex sha256, a url, and same-origin provenance under `public/aura-assets/`. | Use `aura3d assets add` or `shasum -a 256 <file>`; never omit `hash` in `defineAuraAssets(...)`. |
