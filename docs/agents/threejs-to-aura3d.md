# If you would write this in three.js, write this in Aura3D

Read this first. Aura3D is a standalone engine with its own renderer: you describe a scene as typed nodes and `createAuraApp` owns the renderer, camera aspect, resize, loop, context loss and disposal. Do not port that plumbing, delete it. Every Aura3D line below is type-checked against the engine in [`recipes-src/translation-table.check.ts`](recipes-src/translation-table.check.ts) (`pnpm exec tsc -p docs/agents/recipes-src/tsconfig.json`). Complete scenes with no admitted models: [`recipes.md`](recipes.md) recipes 8 to 15.

| If you would write (three.js) | Write (Aura3D) | Difference that bites |
| --- | --- | --- |
| `Scene` + `PerspectiveCamera` + `WebGLRenderer` + `setAnimationLoop` | `scene({ background }).camera(camera.perspective({ position, target, fov }))` then `createAuraApp("#app", { scene })`; per frame `app.onFrame((f) => ...)` with `f.dt`; `await app.ready()` | No renderer, resize or loop code. Mount target is a `<canvas>` or a sized wrapper. |
| `new Mesh(geometry, material)` | `primitives.box({ name, size: [w, h, d], material: material.pbr({ color }) })` (also `sphere`, `plane`, `cylinder`, `capsule`, `cone`, `torus`, `torusKnot`, `lathe`, `extrude`, `tube`) | Primitives are unit shapes scaled by `size`. `sphere` size is the **diameter**; `plane` is `[w, 1, d]` and lies in XZ (`size: [w, d]` is accepted and means the same). Unknown option keys are reported, not ignored. |
| `mesh.position.set(...)`, `rotation`, `scale` | Build time: `.position(x, y, z).rotate(x, y, z).scale(2)`. Runtime: `.runtime({ id, mutable: true })`, then `app.nodes.require(id).setPosition(x, y, z)`, `.setRotation`, `.setScale` | A node you move later needs `runtime({ id, mutable: true })`. Handles have `set*`, not `.position.x`. Vectors are tuples, not `Vector3`. Builder `.rotation(x, y, z)` is accepted as `.rotate(x, y, z)`. |
| `Group` / `Object3D` hierarchy, bones as groups | `group("arm", [children], { position }).runtime({ id, mutable: true })` | Children use local transforms; a group's origin is its pivot. |
| `BufferGeometry` + `setAttribute` + `setIndex` | `geometry.custom(geometry.define({ positions, normals, uvs, colors, indices, bounds }), { name, material })` | Typed arrays in; `bounds` required; `colors` are per-vertex RGBA. `geometry.dynamic` for geometry you rewrite. |
| `MeshStandardMaterial` | `material.pbr({ color, roughness, metallic, emissive, opacity })` (`material.standard(...)` is the same call) | Also `physical` (clearcoat), `emissive`, `toon`, `matcap`. Colour is a CSS string. `side: "double"` means `doubleSided: true`; `transparent`, `wireframe`, `flatShading` have no equivalent and are reported (see [`guessable-api.md`](guessable-api.md)). |
| `ShaderMaterial` | `material.custom({ glsl: { vertex, fragment }, uniforms: { t: { type: "f32", value: 0 } } })`; `handle.setUniform("t", v)` | GLSL 3.00 (`in`/`out`, write `outColor`). Prelude names: `position`, `normal`, `uv`, `modelViewProjectionMatrix`, `modelMatrix`, `cameraPosition`, `uTime` (wall-clock seconds; advances only while the app redraws every frame: give the node `.runtime({ id, mutable: true })` or register `app.onFrame(...)`, else a static scene draws once and `uTime` looks frozen). Node/TSL: `material.node`. |
| `DirectionalLight` + `castShadow` | `lights.directional({ position, target, intensity, shadow: true })` | `shadow: true` on the light (`castShadow: true` is accepted as the same); meshes take `castShadow` / `receiveShadow`. Also `point`, `spot`, `hemisphere`, `ambient`, `rect`. |
| `scene.environment = pmrem` | `environments.neutral({ intensity, background: false })` (also `studio`, `outdoor`, `hdri`, `preset`) | Metals render dark without an environment. `looks.preset(id)` bundles environment, key light, fog and grade. |
| `scene.background = sky shader`, `Sky` | `sky.preetham({ sun: { elevationDeg, azimuthDeg } })`, `sky.gradient`, `sky.dayNight` | Move the sun live with `app.atmosphere.setSky({ sun })`. |
| `scene.fog = new FogExp2` | `effects.fog({ color, density })` | A scene node, not a property. |
| `InstancedMesh` + `setMatrixAt`/`setColorAt` | `instances.cone({ name, transforms: [{ position, rotation, scale }], colors: ["#...", ...], material })` | One draw call per node. Instance colour multiplies the material colour: use a `#ffffff` base material. |
| `light.intensity = v`, `material.color.set(c)`, `material.opacity = a`, `material.emissive.set(c)` | `app.nodes.require(id).setIntensity(v)` / `.setColor(c)` / `.setOpacity(a)` / `.setEmissive(c, intensity?)` | Lights write `setLight({ intensity, color })`; meshes write `setMaterial({ ...material, color })`. A setter that does not apply to the node kind (intensity on a mesh, colour on a model or shader material) throws and names the call to use. |
| `AnimationMixer` + `clipAction().play()` | GLB: `app.nodes.require(id).play("Idle", { loop: true, crossFade: 0.3 })`. Procedural: set joint handles in `onFrame` | Clips come from the file (`assets inspect --animation`). |
| `OrbitControls` | `interactions.orbit({ target: "node-name" })` + `camera.orbit({ position, target, fov })` | `target` is a node **name**, not a point. |
| `Raycaster.intersectObjects` | `raycast({ origin, direction })` or `interactions.pointer({ target })` + `bindPointerInteractions(app, listener)` | Returns hits against scene nodes, no object references. |
| `EffectComposer` + `UnrealBloomPass` | `effects.bloom({ intensity, threshold, radius })`, `effects.vignette`, `effects.colorGrade` | Passes are scene nodes; no composer. |
| `TextGeometry`, CSS2D labels | `text3D("Aura3D", { size, depth })`, `labels.billboard("score", { position })` | HUD belongs in the DOM. |
| `Points`, particle libraries | `effects.particles({ rate, lifetime: [a, b], speed, size, color, blend: "additive" })` | Built-in sprite atlas needs no art. |
| `geometry.dispose()`, `renderer.dispose()` | `app.dispose()` | One call disposes everything the app made. |
| `Vector3`, `Clock` | `[x, y, z]` tuples at option sites; `Clock` from `@aura3d/engine`; `Vector3` from `@aura3d/math/three` | Mutable three.js-shaped math lives only in `@aura3d/math/three`. |

Guessed names: every three.js spelling that models actually tried, with the decision for each (alias, reported with a suggestion, or documented), is in [`guessable-api.md`](guessable-api.md). Unknown builder options are reported once with a "did you mean" suggestion (`OPTION_IGNORED`; strict mode throws).

Not here: `GLTFLoader` (use a typed asset, `model(assets.x)`; see [`asset-workflow.md`](asset-workflow.md)), `renderer.toneMapping` (use the look preset's `output`, or `output: { toneMapping: "aces" }`; the TypeScript type lists only `none, linear, reinhard, aces, agx, neutral, cineon`, and at runtime `"aces-filmic"` / `ACESFilmicToneMapping` map to `"aces"` while unknown names throw), custom render targets and `EffectComposer` chains (no equivalent; check `docs/migration/from-threejs.md`).

Porting an existing file: `npx @aura3d/cli@latest migrate three "src/**/*.ts"` lists what maps, what is approximate and what has no equivalent; it is a worklist, not a drop-in conversion. Full mapping with verdicts: [`docs/migration/from-threejs.md`](../migration/from-threejs.md).
