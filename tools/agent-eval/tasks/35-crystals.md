# Task 35: faceted crystal cluster

Build a scene with {{LIBRARY}}.

Requirements:
1. A cluster of at least five crystals built as custom geometry (not stock primitives): each a faceted prism with a pointed top, flat-shaded with a distinct colour per face, with different heights and tilts.
2. The cluster rotates slowly on a pedestal or ground disc.
3. Glittering sparks (a particle effect) rise gently around the cluster.
4. A dark moody background with rim lighting. Frames differ over time.
