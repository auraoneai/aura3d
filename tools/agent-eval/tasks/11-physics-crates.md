# Task 11: Crate pyramid and wrecking ball

Build a single-page browser app with the provided framework, served by vite, rendering to the canvas with id #app. Show an outdoor concrete yard containing a stack of wooden crates arranged as a pyramid of 5 rows (5,4,3,2,1 crates, 15 in total, each crate a 1 x 1 x 1 cube). The stack must stand stably under gravity without collapsing on its own. Beside the stack, a heavy steel wrecking ball hangs from a tall crane arm on a rigid chain or rope (a pendulum with a fixed pivot and fixed length of about 6 units). The user presses an on-screen button 'Swing' to pull the ball back to a starting angle of 60 degrees and release it; it then swings down and smashes into the pyramid, scattering crates under rigid-body physics (gravity, collisions, friction, restitution). A 'Reset' button rebuilds the stack and returns the ball to rest. Use a fixed physics timestep. Add a soft key light with shadows, a subtle sky or background, and a camera that frames both the crane and the stack. Expose a read-only window.__TASK_STATE__ = { phase: 'ready'|'swinging'|'settled', crates: number, displaced: number, ballAngleDeg: number } updated every frame, where displaced counts crates whose centre has moved more than 0.75 units from its initial position. No external network assets.
