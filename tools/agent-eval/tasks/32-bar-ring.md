# Task 32: animated bar ring

Build a scene with {{LIBRARY}}.

Requirements:
1. 64 bars arranged in a circle, standing on a floor, each bar a box.
2. Each bar's height animates over time from a mix of sine waves (like an audio visualizer) and each bar has its own colour from a smooth hue gradient around the ring.
3. The bars must be drawn efficiently (instanced, not 64 separate scene objects).
4. Soft lighting with shadows on the floor, camera slowly orbiting the ring.
