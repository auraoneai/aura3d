# Task 10: Domino chain reaction

Build a single-page browser app with the provided framework, served by vite, rendering to the canvas with id #app. The scene is a tabletop with a curved line of 30 upright domino tiles (each a thin box, roughly 0.2 wide, 1.0 tall, 0.5 deep) spaced so that each tile can topple onto the next. A small heavy ball rests on a short ramp at the start of the line. A visible on-screen button labelled 'Release' lets the user roll the ball down the ramp, which strikes the first domino and starts a chain reaction in which the tiles topple one after another under real rigid-body physics (gravity, collisions, friction). A second button labelled 'Reset' restores every tile and the ball to the initial arrangement so the run can be repeated. Use a fixed physics timestep so the outcome is repeatable. Light the scene with a soft shadow-casting key light, give the table and tiles distinct materials, and frame the camera so the whole domino path is visible. Expose a read-only object window.__TASK_STATE__ = { phase: 'ready'|'running'|'settled', total: number, toppled: number, ballReleased: boolean } updated every frame, where a tile counts as toppled when it has tilted more than 60 degrees from vertical. Add no external network assets.
