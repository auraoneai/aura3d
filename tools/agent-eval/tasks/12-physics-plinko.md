# Task 12: Plinko board with ball counting

Build a single-page browser app with the provided framework, served by vite, rendering to the canvas with id #app. Show a tall upright pegboard seen from the front (a Plinko-style board, roughly 8 units wide and 12 units tall, enclosed by side walls and a transparent front) with a staggered grid of fixed round pegs (at least 7 rows, alternating 6 and 7 pegs per row). Under the board are 7 equal-width collection bins separated by dividers, numbered 1 to 7 left to right with the numbers visible on screen. A 'Drop 20 Balls' button spawns 20 small spheres, one every 0.25 simulated seconds, from the top centre with a tiny deterministic horizontal offset derived from the ball index (offset = ((i * 37) % 11 - 5) * 0.02), and they bounce down through the pegs under rigid-body physics (gravity, collisions, restitution about 0.4) into the bins. Use a fixed physics timestep so the result is repeatable. Each bin shows a live count of balls resting in it. A 'Reset' button clears all balls and counts. Light the board with a key light and rim light, give pegs, balls and bins distinct materials, and frame the camera so the whole board is visible. Expose a read-only window.__TASK_STATE__ = { phase: 'ready'|'dropping'|'settled', spawned: number, bins: number[7], total: number } updated every frame, where bins counts balls resting in each bin and total is the sum. No external network assets.
