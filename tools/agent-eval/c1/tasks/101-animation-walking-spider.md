# Task 10: Walking spider from primitives

Build a single-page browser app with the provided framework, served by vite, rendering to the canvas with id #app. Show a spider made only from simple geometric shapes (a body made of two or more primitives and eight jointed legs, each leg having at least two segments) walking in place on a flat ground plane. The legs must move in an alternating gait: legs on opposite diagonals move together, and each leg visibly lifts, swings forward and plants again. The body should bob slightly with each step. The motion must loop seamlessly with a period of about 2 seconds and run continuously without user input. Use a neutral studio-style backdrop with soft lighting and shadows so the shape reads clearly from a three-quarter camera that frames the whole spider. Do not load external model files.
