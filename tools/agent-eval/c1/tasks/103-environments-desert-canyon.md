# Task 10: Desert canyon at dusk with slow camera flythrough

Build a single-page browser app with the provided framework, served by vite. It must render one full-viewport canvas with id #app. The scene is a desert canyon at dusk: tall layered sandstone walls on both sides of a winding dry riverbed, warm orange and magenta low sun near the horizon, a cool blue-violet sky gradient overhead, long soft shadows, and a few scattered boulders and dead shrubs on the canyon floor. Fine atmospheric haze should make distant walls fade toward the sky colour. The camera performs a slow, smooth, looping flythrough along the canyon floor at roughly eye height, gently drifting left and right, with no user input needed. Do not rely on any external image or model downloads; build everything procedurally or from assets the framework already provides. The page must show no console errors and must keep rendering continuously.
