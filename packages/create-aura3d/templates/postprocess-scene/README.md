# Aura3D postprocess scene

Three-compat starter on the public `@aura3d/engine` API.

```bash
npm install
npm run dev
npm run test
```

Heroes: two repository-owned showcase GLBs with real emissive materials
(`luma` Cyberpunk_MAT, `miko` glow mat) blooming through the `neon-arcade`
look's post pipeline plus an explicit `effects.bloom` node.

Mirrors the three.js r185 example `webgl_postprocessing_unreal_bloom`
(emissive subjects on a dark field under bloom); composition mirror only,
no parity claim.
