# Aura3D large scene

Three-compat starter on the public `@aura3d/engine` API.

```bash
npm install
npm run dev
npm run test
```

Hero: instanced Kenney Mini Forest props (CC0-1.0) — 42 trees + 24 rocks as
`instances.model` draw classes — scattered deterministically over a meadow
under the `outdoor-day` look, orbited high.
