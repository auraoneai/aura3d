# Aura3D architecture interior

Three-compat starter on the public `@aura3d/engine` API.

```bash
npm install
npm run dev
npm run test
```

Hero: a textured Kenney **Modular Dungeon Kit** room GLB (CC0-1.0) under the
`interior-warm` look — warm interior light, fog, and grade — with orbit
control.

Mirrors the three.js r185 example `webgl_lights_rectarealight` (an interior
lit by area light); composition mirror only, no parity claim.
