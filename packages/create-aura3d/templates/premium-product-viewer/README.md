# Aura3D premium product viewer

Three-compat starter on the public `@aura3d/engine` API.

```bash
npm install
npm run dev
npm run test
```

Hero: the typed Khronos glTF-Sample-Assets **ToyCar** GLB (CC0-1.0, Microsoft)
— the sample that exercises `KHR_materials_clearcoat`,
`KHR_materials_transmission`, and `KHR_materials_sheen` — on a plinth under
the `product-studio` look with `camera.frameAsset` orbit autoframing.

Mirrors the three.js r185 example `webgl_materials_physical_clearcoat` (the
DamagedHelmet clearcoat demo); this is a composition mirror, not a parity
claim — the look and material stack come from Aura3D.
