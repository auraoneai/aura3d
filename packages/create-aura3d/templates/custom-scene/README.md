# Aura3D custom threejs migration

Three-compat starter on the public `@aura3d/engine` API.

```bash
npm install
npm run dev
npm run test
```

Hero: a typed Kenney Pirate Kit ship GLB (CC0-1.0) on a harbour plane under
the `outdoor-day` look — the migration starter showing a hand-rolled
three.js scene as engine source.
