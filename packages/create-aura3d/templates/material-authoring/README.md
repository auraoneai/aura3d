# Aura3D material authoring

Three-compat starter on the public `@aura3d/engine` API.

```bash
npm install
npm run dev
npm run test
```

Hero: a grid of five 64×32 tessellated swatch spheres built through C-07
custom primitive geometry (`defineAuraCustomGeometry`) under the
`product-studio` look, plus one typed GLB swatch (Kenney Car Kit
sedan-sports, CC0-1.0) so authored materials sit next to a real asset's
material stack.
