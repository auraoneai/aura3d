HUD theme fonts (packages/game/src/fonts) - licensed web cuts, not open source

Every .woff2 file in this directory is an unmodified copy of a WOFF2 web cut
from the AuraOne licensed font library (paths below are relative to that
library). They are commercial fonts licensed for web self-hosting on
AuraOne-served pages only:

- Do not install them as desktop fonts, convert them to other formats, subset
  or modify them, or redistribute them outside AuraOne-served game routes.
- They are not part of the npm tarball: tools/finalize-dist copies no .woff2.
- A game copies the files its theme needs into its own app folder and
  registers them with registerGameFonts(baseUrl, document).
- Build and run time never read the font library; these copies are the source.
