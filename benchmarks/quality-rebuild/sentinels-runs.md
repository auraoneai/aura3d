# IC-0 sentinel baseline runs

The GitHub `Quality Rebuild Capture` workflow runs the benchmark scenes flag-off on
`macos-14` whenever a commit on `aura3d-quality-rebuild/audit` touches this tree.
IC-0 requires two such runs; this file is the second triggering commit and doubles
as the run ledger. GitHub run ids are recorded in
`docs/project/aura3d-quality-rebuild/evidence/prd15/baselines/phase0.json` on the
`qr/prd15-ic0-base` branch.
