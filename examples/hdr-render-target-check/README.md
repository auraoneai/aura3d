# HDR render-target contract fixture

This source proves a bounded WebGL2 RGBA32F render target, float readback, an
overbright sample, and deterministic tone mapping. The browser host lives at
`tests/fixtures/visual-examples/hdr-render-target-check/index.html`.

It is not a public 2.0 example, an HDR/IBL scene, or same-scene Three.js parity
evidence.
