# Asset attribution

None of these assets come from the original game.

All 3D characters, landmarks, gates, hazards, floating islands, pagodas, lanterns, carts, and pickups in `Serpentine Sky Run` (`saiyan-snake-way-port`) are authored 100% procedurally in TypeScript on `@aura3d/engine` (`skyRunnerRig.ts`, `art/proceduralModels.ts`, and `world.ts` using `geometry.define`, `geometry.multiMaterial`, `group`, and `material.*`). Zero Meshy or external `.glb` files are bundled or fetched.
