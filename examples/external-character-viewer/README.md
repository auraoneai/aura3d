# Animation Studio shared character surface

This directory contains the reusable typed-character workflow mounted by
`apps/animation-studio-pro`. It is not a separate public example: the retained
`examples/character-animation-viewer` route already demonstrates the same
robot, root runtime, named clips, playback, and timeline controls in a cleaner
example presentation.

The standalone host used for provenance, timeline-scrub, and pose-change
browser evidence lives in `tests/fixtures/external-character-viewer`.
