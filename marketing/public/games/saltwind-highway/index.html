A chase camera that keeps up

The camera smooths its height and sideways offset relative to the road. It tracks distance along the highway directly, keeping the car in frame even at speed.

Build your own game

Start with a car, a chase camera and a circuit with working checkpoints. Run these commands, then open the address printed in your terminal.

npx create-aura3d@5.6.0 my-game --template racing-starter
cd my-game
npm install
npm run dev
