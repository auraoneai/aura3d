Racing and driving

Craterline GP

Race a bike around a lunar rim. Split off the main line and find your way back to the surface.

Play Craterline GPHow it works

Landing after a zero-gravity drift

The game indexes drivable triangles in a spatial grid. It sweeps a segment along the rider’s movement to find the exact patch of track they meet on re-entry.

Build your own game

Start with a car, a chase camera and a circuit with working checkpoints. Run these commands, then open the address printed in your terminal.

npx create-aura3d@latest my-game --template racing-starter
cd my-game
npm install
npm run dev
