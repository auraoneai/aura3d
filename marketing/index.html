TypeScript 3D engine, version 4.3.6

A lit 3D product in 10 lines of TypeScript.

Aura3D is the TypeScript engine for agent-written browser 3D that ships the whole stack: lighting looks, typed and licensed assets, Rapier physics, Recast navigation, a game kit and deploy checks. The three.js version of the same scene is 38 lines before orbit controls.

main.ts 10 lines 
import { camera, createAuraApp, interactions, looks, model, scene } from "@aura3d/engine";
import { assets } from "./aura-assets";

createAuraApp("#app", {
  scene: scene()
    .add(looks.preset("product-studio"))
    .add(model(assets.product, { name: "product", targetHeight: 1.6, castShadow: true }))
    .add(interactions.orbit({ target: "product" }))
    .camera(camera.frameAsset(assets.product, { targetHeight: 1.6 })),
  ...looks.appOptions("product-studio")
});

three.js main.ts 38 lines 
import * as THREE from "three";
import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js";
import { HDRLoader } from "three/addons/loaders/HDRLoader.js";

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
renderer.setSize(innerWidth, innerHeight);
renderer.toneMapping = THREE.NeutralToneMapping;
renderer.shadowMap.enabled = true;
document.querySelector("#app")!.appendChild(renderer.domElement);

const scene = new THREE.Scene();
scene.background = new THREE.Color("#2b2f36");
const camera = new THREE.PerspectiveCamera(35, innerWidth / innerHeight, 0.1, 100);
const pmrem = new THREE.PMREMGenerator(renderer);
new HDRLoader().load("/hdri/studio_small_08_1k.hdr", (hdr) => {
  scene.environment = pmrem.fromEquirectangular(hdr).texture;
  scene.environmentIntensity = 1.1;
  hdr.dispose();
});

const key = new THREE.DirectionalLight("#ffffff", 2.4);
key.position.set(6.52, 18.39, 13.98);
key.castShadow = true;
key.shadow.mapSize.set(2048, 2048);
scene.add(key);

new GLTFLoader().load("/aura-assets/product-fixture.glb", (gltf) => {
  gltf.scene.traverse((o) => { if ((o as THREE.Mesh).isMesh) o.castShadow = o.receiveShadow = true; });
  scene.add(gltf.scene);
  const box = new THREE.Box3().setFromObject(gltf.scene);
  const center = box.getCenter(new THREE.Vector3());
  const dist = box.getSize(new THREE.Vector3()).length() / (2 * Math.tan((camera.fov * Math.PI) / 360));
  camera.position.copy(center).add(new THREE.Vector3(0.5, 0.35, 1).normalize().multiplyScalar(dist));
  camera.lookAt(center);
});

addEventListener("resize", () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
renderer.setAnimationLoop(() => renderer.render(scene, camera));

Everything three.js leaves to you, built in.

three.js gives you a renderer. Aura3D gives you the renderer, the lighting, the asset pipeline, the game kit and the deploy checks, typed end to end and built for AI coding agents.

Why Aura3D over three.js
What Aura3D includes and what three.js leaves to you, by need: lighting, post effects, model loading, asset licensing, production safety, game shell, replay, high refresh rates, blank-screen recovery and AI coding agents.

Loading a model model(assets.robot): typed key, compile-time check. GLTFLoader and a string path.

Production safety Unverified models don't draw. Any URL loads.

Check every asset before you ship.

aura3d check-deploy fails the build when a hashed asset is missing, a stray file sneaks into dist, or a model fails validation. Add --browser to load every route in headless Chromium and fail on failed requests and console errors, or --release for licence and quality gates.

Pre-deploy checklist

  • ✓Typed imports resolve against the public API.
  • ✓Every shipped asset carries a hash and a typed reference.
  • ✓Unreferenced files in dist fail the check.
  • ✓check-deploy --browser flags failed requests when a route boots.
  • ✓check-deploy --browser reports console errors on the routes you ship.
  • ✓--release adds licence and quality gates.
  • ✓Every template ships route-health and screenshot tests.
