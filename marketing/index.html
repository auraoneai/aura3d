Aura3D vs. Three.js

Five decisions, already made.

The same scene, twice. Aura3D declares the parts; raw Three.js makes you own every wire.

Full comparison
Aura3D 4.1.2 compared with raw Three.js across scene boot, asset pipeline, materials and lighting, physics, and pre-deploy verification.
Capability Aura3D 18 lines Raw Three.js three@0.185.x
Scene boot 18 lines. createAuraApp() owns the renderer, camera, resize, clock, context loss, and dispose. ~120 lines of WebGLRenderer, camera, ResizeObserver, requestAnimationFrame, and recursive dispose().
Asset pipeline Compile-time typed refs from aura.assets.json, with hashes, SPDX, and clip metadata. Untyped URLs and manual Draco / KTX2 WASM loader wiring.
Materials & lighting Physical PBR, procedural sky, IBL, and AgX / ACES tone mapping built in. Manual PMREMGenerator, RGBELoader, and tone-mapping setup.
Physics Deterministic fixed-step Rapier, CCD, joints, and character and vehicle controllers. Bring your own rapier3d-compat, WASM init, fixed-step loop, and vehicle math.
Pre-deploy verification aura3d check-deploy checks route health, assets, and zero console errors. Manual browser checks; no standard asset or console-error gate in CI.

You own every loader, resize, and teardown path.

scene.ts 18 lines 
import { createAuraApp, effects, environment, light, model, orbitCamera, post } from '@aura3d/engine';
import { assets } from './aura-assets';
// The renderer, resize observer, and dispose loop are handled by the app.
const app = await createAuraApp({
  target: '#app',
  scene: [
    environment.studio({ intensity: 1.15, sky: 'procedural-dusk' }),
    orbitCamera({ position: [2.8, 1.9, 3.6], target: [0, 0.85, 0] }),
    light.directional({ position: [4, 7, 5], intensity: 3.2, castShadow: true }),
    model(assets.damagedHelmet, {
      position: [0, 0.85, 0],
      castShadow: true,
      clip: 'Idle',
    }),
    effects.contactShadows({ opacity: 0.45, blur: 1.6 }),
    post({ toneMapping: 'agx', exposure: 1.1, bloom: { intensity: 0.35 } }),
  ],
});

Typed assets, lighting, shadows, and post are declared, not wired.

One import for the whole stack.

The engine owns the renderer, camera, resize observer, clock, context-loss recovery, and teardown. You compose the parts that make the scene yours.

import { createAuraApp, environment, model, orbitCamera } from '@aura3d/engine';
import { assets } from './aura-assets';

await createAuraApp({
  target: '#app',
  scene: [
    environment.studio({ intensity: 1.15 }),
    orbitCamera({ distance: 3.4 }),
    model(assets.damagedHelmet, { clip: 'Idle' }),
  ],
});

Verification & deploy

Prove the route before you ship it.

A 3D page is only finished when it loads clean. The checklist, browser matrix, and CLI checks below are the ones Aura3D runs on its own routes.

Pre-deploy checklist

  • ✓Typed imports resolve against the public API.
  • ✓Every asset path has a hash and a typed ref.
  • ✓Each route boots with no failed requests.
  • ✓Zero console errors on the routes you ship.
  • ✓aura3d check-deploy passes before publish.
