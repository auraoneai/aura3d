Aura3D 4.0.1 vs. Raw Three.js
Why Teams Choose Aura3D 4.0.1 Over Raw Three.js

Stop assembling 14 fragile npm packages.
Boot a verified 3D scene in 18 lines of TypeScript.

Three.js is a legendary low-level rendering kernel—not a complete application engine. The moment you step beyond a spinning cube, raw Three.js forces your team to hand-wire WebGLRenderer, PerspectiveCamera, OrbitControls, GLTFLoader, DRACOLoader, KTX2Loader, RGBELoader, EffectComposer, PMREMGenerator, Rapier3D, Recast, manual resize observers, and recursive dispose() loops just to keep a single route from leaking GPU memory. Aura3D 4.0.1 (@aura3d/engine@4.0.1) ships the entire browser 3D application stack in one zero-dependency, MIT-licensed TypeScript SDK.

Animation Studio

Describe a scene. Watch it perform.

Type a prompt — get a rendered animated short. The same prompt, every time. Scene intelligence isn't code you write; it's a generated EpisodeDocument played by one generic renderer with zero scene-specific constants. And the director isn't a model we bundle — it's your own coding agent, driving a validated Scene-Tool CLI. No bundled LLM. No API key.

The cast is parsed straight from your words and bound to graded humanoid rigs. Sets are keyword-routed — an office becomes an office, a forest a meadow — never a moon-garden default. A shared retargeted motion library drives everyone, with velocity-gated locomotion so planted feet stay planted and captions timed to the length of the line. A ten-gate quality suite stands guard: it rejects stiff bodies, lip-only motion, and fabricated proof. Every gate measures a real signal — nothing hard-codes a pass.

The web studio is a three-pane NLE — a Director Console, live previews, and real validated commands, not a mockup. Renders are silent by design; AuraVoice owns the voice. A clean, stylized look you can watch in minutes — and when you want photoreal characters, drop in your own rigged GLB and it renders them too. Describe the next shot, and the scene changes. It just renders.

// Typed GLB + 4.0.0 effects.* pipeline: register once, then compose the scene.
import {
  createAuraApp, scene, model, camera,
  lights, effects, looks
} from "@aura3d/engine";
import { assets } from "./aura-assets";

createAuraApp("#app", {
  ...looks.appOptions("studio-product"),
  diagnostics: { overlay: true },
  scene: scene({ background: "#05070a" })
    .add(model(assets.boombox, { scale: 1.2 }))
    .add(lights.studio({ intensity: 1.2 }))
    .camera(camera.orbit({ distance: 4 }))
    .add(effects.bloom({ intensity: 0.28 }))
    .add(effects.ambientOcclusion({ intensity: 0.35, radius: 0.45 }))
    .add(effects.contactShadows({ opacity: 0.45, blur: 1.6 }))
    .add(effects.vignette({ intensity: 0.22 }))
});
// Typed assets & 4.0.0 effects.* keep models and post-processing deterministic.
