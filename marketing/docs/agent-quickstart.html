Your first 3D scene

Create a product viewer with a model, studio lighting, and an orbit camera. Everything you need for the first frame comes with the starter.

Terminal
npx create-aura3d@5.6.0 my-scene --template product-viewer
cd my-scene
npm install
npm run dev

Make your first edit

  1. Open the local viewer

    Run the four commands above in a terminal with Node.js and npm installed. Open the local URL printed by Vite. Drag to orbit the model on its plinth.

  2. Change the framing

    In src/main.ts, find camera.frameAsset(assets.product, …). Change its padding from 1.6 to 2 and save. The camera leaves more space around the model.

  3. Build the static site

    In another terminal, run npm run build from my-scene. The finished files go in dist/. Follow the deployment guide to check the build.
