Ship what the evidence proves. Label everything else.

Aura3D 2.0.0 is a TypeScript browser 3D SDK with bounded game-presentation evidence—not an automatic production game engine or a universal renderer-parity claim. The retained-example visual audit and exact installed-package comparison are current; public promotion remains held on clean-machine, repeated-performance, independent-human, publication, and production-site gates.

Claims

Current public boundary, in plain language.

Every promoted capability names its path, retained proof, and limitation.

Proven

Typed browser 3D workflow

Create Vite apps, register GLB/glTF assets, import generated TypeScript references, compose scenes, test routes, and deploy static output.

Open reference
Bounded

Named game-presentation evidence

Turbo Drift Circuit and Skyline Runner retain scoped geometry, contact, gameplay, route, and automated visual-QA evidence. They remain prototype-blocked and cannot be promoted.

Open reference
Not claimed

No arbitrary GLB-to-game conversion

Catalog labels alone do not make an asset game-ready. Uncertified geometry, stale hashes, bad scale, or failed composition block public status.

Not claimed

No production game-engine parity

The release does not claim production physics, arbitrary mesh collision, AI opponents, netcode, Unity/Unreal parity, or commercial game completeness.

Renderer

Route-specific pixels only

Root-wide PBR, HDR/IBL, postprocess, WebGPU, skinning, or morph claims require exact public-route browser evidence.

Diagnostics

Labs stay labeled

Data Galaxy, Particle Lab, and the two game-layer harnesses remain useful engineering evidence without being promoted as public product examples.
