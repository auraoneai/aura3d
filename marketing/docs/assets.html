Bring your model into the scene

Register a GLB or glTF file once. The CLI records its source and generates a TypeScript name you can use in your scene.

Terminal
npx @aura3d/cli@5.7.1 assets add ./assets/product.glb --name product

import { createAuraApp, sceneKits } from "@aura3d/engine";
import { assets } from "./aura-assets";

createAuraApp("#app", sceneKits.productViewer(assets.product).toAppOptions());
