Aura Clash

Aura Clash Arena is the live Aura3D 4.3.7 fighting-game development showcase: typed GLB fighters, a neon arena, responsive combat controls, audio cues, accessibility controls, evidence routes, screenshot capture, and deployed TypeScript game-runtime proof.

What it currently proves

Typed assets

Runtime GLBs are registered through Aura3D typed asset references with provenance, checksums, clip maps, and release evidence.

Game loop

Movement, W jump, Space dash, Shift block, S down, air attacks, crouch attacks, L special, KO, reset, timer, health, and round state are automated.

Developer evidence

The evidence route exposes provenance, typed asset names, controls, gameplay state, renderer proof, audio proof, and deployed route health.

Accessibility

Reduced motion, reduced flash, and high contrast controls are part of the showcase UI.

Release gates

The release evidence covers gameplay, audio, performance, screenshot capture, and deployed route parity.
