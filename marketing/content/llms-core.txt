## Read first

1. From three.js: `docs/agents/threejs-to-aura3d.md` maps each idiom (type-checked). Do not port renderer, resize, loop or disposal code; `createAuraApp` owns them.
2. Two 3D modeling paths (never single-mesh Meshy clay or 1-box programmer art):
   - Clean, UV'd or rigged GLBs via `model(assets.x)` from the project or open CC0/CC-BY sources.
   - Multi-part, multi-material procedural sculpting in `@aura3d/engine`: compose `primitives.extrude|lathe|tube|roundedBox|polyhedron`, `geometry.define|applyMatrix4|merge|multiMaterial` and `instances.custom` across 3 to 8 physical materials (`material.carPaint`, `lacquer`, `brushedMetal`, `ceramic`, `studioGlass`, `fabric`, `physical`) so bevels and seams catch IBL and key-light speculars. Complete procedural scenes: `docs/agents/recipes.md` recipes 8 to 15.
   - Organic characters, creatures and hulls: `@aura3d/engine/sculpt`: SDF bodies (`sculptOrganicSdfMesh`), limbs (`sculptSdfLimbChainMesh`), heads, hair and garments for `geometry.multiMaterial` (`docs/api/sculpt.md`). Bake once at load, never per frame.

## More pitfalls

- `looks.preset(id)` loads `public/hdri/<file>.hdr` (scaffolds ship it); if missing, the scene gets a procedural probe and a `LOOK_HDRI_MISSING` warning in `app.diagnostics()`.
- Follow cameras clip into walls unless cleared: `computeCameraClearance(target, desired, obstacles, { minDistance, allowVerticalRise })` each frame, then ease the result (`docs/api/motion-camera-clear.md`).
- Size pools (bullets, traffic, particles) from the measured peak, or objects pop.
- 5.7.0: model and primitive handles inside a `group(...)` are parent-local (5.6: world). Convert 5.6 world values to the parent's space or make the node top-level; world reads: `getWorldPosition()`.
- A dark hero on a dark set vanishes: add a rim or back light or a lighter accent; check a back-view frame. HUD words (a colour, a name) must match the drawn frame.
- Judge steady state (frame 1 is lit before the probe bakes): compare captures at 3, 25 and 60 s before reverting anything.

## Fast path

Why Aura3D: three.js is a rendering library; Aura3D is a complete engine with its own renderer: lighting, VFX, asset pipeline, AI generation, game kit, physics and deploy checks are built in, and every model is typed, hashed and licensed. `renderer: { backend: "auto" }` gives WebGPU with a WebGL2 fallback (all 30 showcase games; WebGL2 without it); `worker: { createWorker }` (`@aura3d/engine/worker`) renders off the main thread; `aura3d import-three` brings a three.js scene factory across as a typed asset. Comparison: `docs/aura3d-vs-threejs.md`.

Five commands to a running scene:

```bash
npx create-aura3d@latest my-scene --template mini-game   # also writes this file and the Aura3D skills
cd my-scene && npm install
npm run dev                                              # Vite on 127.0.0.1
npx @aura3d/cli@latest assets resolve "robot" --name robot   # then use model(assets.robot) from ./src/aura-assets
npm run build && npx @aura3d/cli@latest check-deploy --dist dist
```

Other templates: `product-viewer` (default), `cinematic-scene`, `racing-starter`, `falling-blocks-starter`, `fighting-game`, `character-controller`, `arena-shooter`.
GPU-verified starter scenes to adapt: `starter-product`, `starter-outdoor`, `starter-interior`, `starter-game`, `starter-presentation`.

Read next, in this order: `docs/agents/README.md` (index), `docs/agents/agent-quickstart.md` (first scene), `docs/agents/recipes.md` (copy-and-adapt scenes; recipe 18 is a game shell on the 5.7.0 kits), `docs/agents/claims-and-boundaries.md` (what you may claim). Building a game: read `docs/agents/new-game-checklist.md` and `docs/agents/lessons-learned.md` first, then run `node tools/game-checks/run.mjs <game-slug>`.

## Hello world

Hello world: one typed model under a look preset.

```ts
import { createAuraApp, looks, model, scene } from "@aura3d/engine";
import { assets } from "./aura-assets";

createAuraApp("#app", {
  scene: scene().add(looks.preset("product-studio")).add(model(assets.robot)),
  ...looks.appOptions("product-studio")
});
```

## Quality floor and the never list

- A `looks.preset` supplies image-based light, a shadow-casting key, fog, background and a post grade as one unit. Never wire `lights.ambient()` as the only fill.
- Never a solid void background; the look's sky, biome or studio backdrop owns it.
- Never a hand-placed camera for the subject: `.camera(camera.auto())` frames what the scene holds (`{ subject: "name", fill }` for one node). Hand-built light: `lights.key({ target })` casts the shadow; give it a ground plane.
- Never `pixelRatio`, `qualityProfile`, `safe-basic`, FXAA or `replaceTextures: true` overrides; `looks.appOptions(id)` carries the renderer contract.
- Hero and props: a clean GLB or a multi-part procedural model ("Read first" 2).
- Never emissive cards or sprites faking reflections, puddles or glows; use the look's grade and `effects.*`.
- Never CSS/DOM particles or labels standing in for rendered output. HUD lives in the DOM, the scene does not.
- Gate frame 1 on `app.ready().then(...)` (a top-level `await app.ready()` deadlocks a production build: black page); mutate node handles on restart, never `app.setScene()` again.

## Assets

Do not invent asset paths, URLs or ids; every model is a generated `assets.<key>`.

- `npx @aura3d/cli@latest assets search "<object>"` lists licence-tagged open candidates; `assets resolve "<object>" --name <n>` types the top match; `assets add ./model.glb --name <n>` adds a file (then read `src/aura-assets.ts`).
- No match: prefer a multi-part procedural model (Fast path, `@aura3d/engine/sculpt`); Meshy (`meshy-cli` skill) only on request.
- `assets convert in.fbx --out out.glb` (FBX, OBJ, USD, BVH and more; losses reported). `assets generate "<subject>" --name <k> --kind character --rig --dry-run` prints the fal.ai cost; the paid run admits a `candidate`. `assets normalize` (facing/size), `assets slim` (JPEG normals; glossy ones stay PNG), `assets preview`/`assets thumbnail` (CPU base-colour PNGs).
- Never trust generated PBR maps (`PBR_*` warnings); split body, glass, chrome and tyres; keep normals PNG; lower `normalScale`; judge gloss on a real GPU.
- Material values: car paint = dielectric + clearcoat 1.0 (rough ~0.05), chrome = metal 1 rough ≤0.08; never fix sheen by lowering specular; run `assets inspect --pbr`.
- Clips: `animation import <bvh|fbx|glb|motion.json> --onto rig.glb --out hero.glb`; `animation generate "<motion>" --onto rig.glb --out hero.glb` (fal.ai `FAL_KEY`, ledgered; reruns never pay twice).
- All commands: `aura3d help --json` / `docs/api/cli-reference.md`; exit 0 ok, 1 failed, 2 usage.
- In production a model without same-origin URL, sha256 and provenance draws nothing.

## Kits (build the shell from these)

- `@aura3d/engine/game`: `createGame` (lifecycle, pause, results, DOM HUD, touch controls, audio unlock, juice, sound).
- 5.7.0, never hand-roll: `?autoplay=1` (every game) via `readAutoplayFlag` + `createAutoplayHarness`; `createSnapshotInterpolator` (render interpolation); `createImpactRig`, `createProceduralSfx`, `ScreenFx`, `GameRng` (feel); `createFlipbookAtlas`, `createGradingLut` (VFX sheets), all `@aura3d/engine/game`; humanoid clips: `createHumanoidAnimator` (`/animation`).
- Look (5.7.0): `sky.gradient({ mid, haze, sun: { glow } })` paints a game sky; `shadow: { softness, fit }` sets sun penumbra and a fixed box; `output: { alphaMode: "premultiplied", inputAlphaMode: "premultiplied" }` is a transparent canvas (never a hand-made matte).
- `@aura3d/engine`: `createFixedStepLoop`, `installQaHooks`, `readQaParams`, `createCountedRng` (replay, telemetry: `qa-kit.md`); `defineModelAssets`; `game.racketSports()`, `game.platformer`, `game.racing`, `game.fallingBlocks`, `game.fighting`; `effects.toon`.
- `@aura3d/engine/devtools`: `createAuraTuneOverlay` (live sliders). `RuntimeQualityGovernor` is on by default (`quality-governor.md`).
- `@aura3d/engine/audio`: `createCueBank`, `createStepSequencer`, `createToneLoop`, `createSampleSlices` on the single `AudioContextManager` (never `new AudioContext(`).
- `@aura3d/debug`: `installSafetyNet` (`?diag=1`, quality switches, black-frame self-heal).
- `material.custom` shaders: `#include <a3d_math>`, `<a3d_noise>`, `<a3d_sky>`, `<a3d_fog>`, `<a3d_toon>`; keep `pow`, `normalize`, `sqrt` and divides NaN-safe.

Details: `docs/api/game-kit.md`, `game-autoplay.md`, `game-feel.md`, `humanoid-motion.md`, `qa-kit.md`, `safety-net.md`, `sculpt.md`, `cli-asset-tools.md`.

## Look-dev loop

1. Pick a genre look and 1 to 3 reference frames; write a three-line brief.
2. Build with the look preset and typed assets.
3. Capture frames, judge each against the rubric, fix the single highest-leverage thing, repeat.
4. Stop when every category reads 7 or higher or the loop exits flat. Skill: `aura3d-art-direction`.

## Proof standard

Use every feature freely; every claim ships with a judged capture.

- Name what a capability runs on (`createAuraApp` safe API, `production-runtime`, `rendering` internals, CLI asset pipeline, template scaffold); mark roadmap work as roadmap.
- Public examples show what `@aura3d/engine` renders, backed by route health, typed provenance and a readable frame.
- Three.js comparisons: lead with scope, workflow and code size (`docs/aura3d-vs-threejs.md`); speed and bundle size are not part of the comparison.
- Release integrity: public examples use typed assets (no raw asset IDs/GLB URLs, `unsafeModelUrl(...)`, `three` or `GLTFLoader`); heroes are real models or labelled procedural recipes; particles are Aura3D particles; WebGPU, PBR, postprocess, skinning, morph and game-runtime claims come with browser evidence.
