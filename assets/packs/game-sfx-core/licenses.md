## Mapped categories

Where the §6.9 table asks for a sound no licensed source provides verbatim,
the closest CC0 file was admitted instead and `note`/`derivedFrom` in the
manifest and `sources.json` record the mapping. Substituted ids:

- `sports.*` — Kenney Casino/rpg equivalents (chip/card clacks = table impacts)
- `impact.stone.medium|heavy` — split of the `impactMining`/`impactPlate` families
- `impact.plastic.*` — `impactGeneric`/`impactTin` families
- `impact.rubber-ball.*` — `impactSoft`/`impactPunch` families
- `impact.energy.*` — `forceField`/`laserLarge`/`spaceTrash` (sci-fi pack)
- `footsteps.metal|water|gravel` — `impactPlate`/`slime`+`spaceTrash`/`footstep_snow`
- `whoosh.*` — `knifeSlice`/`drawKnife`/`phaseJump`/`thrusterFire`
- `vehicle.*.layerN.off` — on-load layer run through lowpass + lower rate (ffmpeg)
- `vehicle.van-real|car-sport-real|tyre-skid` — motorcycle/wind excerpts (loop-mastered)
- `ambience.*` — field recordings/ambience loops tiled or trimmed to 32 s beds
