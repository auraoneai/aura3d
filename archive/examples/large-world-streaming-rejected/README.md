# Rejected Large World Streaming Example

Archived and rejected for Aura3D 2.0 after personal inspection. The public
frame was a synthetic collection of generated boxes, rain lines, and telemetry,
not a coherent large world. Its browser spec primarily asserted internal
`oldBranch*Port` state and generated-fixture counters. Keep these files only as
historical implementation evidence; do not publish, export, or cite them as a
current large-world, open-world, streaming, terrain, weather, vegetation,
voxel, or ocean capability.

The 2.0 large-world flagship remains open until a replacement uses a real typed
world asset, a readable first frame, public API ownership, meaningful navigation
or streaming interaction, pixel-backed evidence, and a current same-workload
Three.js comparison.
